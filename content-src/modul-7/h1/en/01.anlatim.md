### What you will learn in this lesson
- The difference between the concepts of artificial intelligence, machine learning and language model
- The basic job of a language model: predicting the next piece (token)
- How the prediction loop produces text
- What the "real calculation" and "simulation" labels mean on this portal

### What you should know first
Nothing. This lesson starts from zero. If you see code, reading it is enough; you do not need to run it.

### Three concepts, three layers
The three terms are often mixed up. Think of them as boxes inside boxes:

```
Artificial intelligence            (the broad umbrella)
  └─ Machine learning             (methods that learn from examples)
       └─ Language model          (a model that learns from text)
```

**Artificial intelligence** is the shared name for systems that do jobs thought to need intelligence. A hand-written list of rules can count too: "if the distance is less than 10 cm, stop." In **machine learning** you do not write the rule; you give examples, and the system finds the pattern itself. A **language model** is a machine learning model that takes its examples from text. Chat assistants like Claude are built on large language models.

### What does a language model do?
A language model's basic task fits in one sentence: *look at what has been written so far and predict the next piece.* In training it sees a huge amount of text and learns which pieces come after which. When it answers, at every step it produces a list of probabilities, chooses one, and adds it to the text.

### The prediction loop
Generating text is the same step repeated:

| Step | Text so far | What the model does |
|---|---|---|
| 1 | robot | "turns" has a high probability, it chooses it |
| 2 | robot turns | "right" has a high probability, it chooses it |
| 3 | robot turns right | chooses "." |

At each step only one piece is added. An answer of six pieces means six separate predictions. The same loop can also produce sentences that look confident but are wrong; you will see this in detail in the hallucination lesson.

### The honesty rule on this portal
In this module the tools run in your browser. There are two kinds of step:
- **Real calculation:** tokenising, counting, probability and accuracy measurement are really calculated.
- **Simulation or template:** steps that stand in for a large model are labelled. Real Claude does not run here; anything marked "model answer" is a hand-written or scripted example.

Reading the label means knowing what the thing on the screen is.

### Summary
Artificial intelligence is the broadest concept; machine learning is the part of it that learns from examples; a language model is the kind that learns from text. A language model predicts the next piece and produces text by repeating this step. On this portal the calculations are real, and steps that stand in for a model are labelled as simulation.
