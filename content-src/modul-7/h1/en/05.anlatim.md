### What you will learn in this lesson
- How to analyse the output of a mini language model in a systematic way
- How to find the source of the strangeness in the output (context limit, recombination, backing off)
- How a generated text is checked by comparing it with the sentences in the corpus
- The benefit and the cost of context length

### What you should know first
Lessons 1-4: a language model predicts the next piece, tokens, bigram and trigram models, backing off, seeds. There is no new tool in this lesson; you will use the tool from lesson 4 as a project. Everything is really counted from the corpus; no question goes to an AI service.

### Look at the output like a detective
Project: a model with a two-word context (a trigram model) starting with `robot`, and three sentences with three different seeds. The real job is not generating the sentence but analysing it. An example output (start `robot`, seed 1, 10 words):

```
robot sağa döner . öğretmen öğrenciye yardım eder . robot yolu
(robot turns right . teacher helps the student . robot the road)
```

Examine the output with three questions:

| Question | In this example |
|---|---|
| Is it in the corpus word for word? | `öğretmen öğrenciye yardım eder .` (the teacher helps the student) appears exactly in the corpus: a copy |
| Is every pair of words in the corpus? | Yes; but the whole sentence may not be |
| When was it built? | After "." the model chose a new sentence start, unrelated to the previous sentence |

### Three sources of strangeness
1. **Exact copy.** The model can produce a sentence it saw in the corpus exactly; this is not "a new idea" but memorisation. Because the corpus is small, it happens often.
2. **Recombination.** `robot ileri gider ve engeli görür` (the robot goes forward and sees the obstacle) does not appear in the corpus as a six-word whole. But `ileri gider ve` and `ve engeli görür` each appear separately. The model lines the pieces up one after another and does not check whether the whole makes sense.
3. **Context limit.** A two-word context does not see the start of the sentence. The topic can jump from "robot" to "teacher", because the context resets after a full stop.

### The cost of a longer context
A longer context makes the text more consistent; but the context must have appeared word for word in the corpus. If data is scarce, a long context is often not found and the model backs off. So the benefit: a more consistent sentence. The cost: more data.

### An honest results report
In your report, write the three sentences, a separate source note for each sentence (copy, recombination or limit) and the seed. This way someone else can reproduce the same result. The reasons large models build silly sentences may be similar to the ones here; but we are not proving that here, we are only seeing it on a small model.

### Summary
The strange sentences of a mini language model come from three places: exact copies from the corpus, meaningless combinations of correct pairs, and a short context not being able to see the sentence. You find the source by comparing the output with the corpus. A longer context makes the text more consistent but needs more data. If you write down the seed, the result can be repeated.
