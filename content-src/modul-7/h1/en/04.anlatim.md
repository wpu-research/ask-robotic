### What you will learn in this lesson
- How the probability of the word that comes after a context is found by counting
- The difference between a bigram and a trigram model
- How the model "backs off" when the context is not in the corpus
- How the seed decides the generation

### What you should know first
Lesson 1: a language model predicts the next piece. Lessons 2 and 3: the idea of tokens. In this lesson we will count words; the tool's calculations are real, but it is a counting table, not a real neural network.

### Probability = count
The mini robot corpus has about forty short sentences. The tool counts the answer to "after this context, which word came how many times?". The probability is that word's count divided by the total:

```
probability(word) = count of the word / count of all words that came after the context
```

Example: in the corpus, `döner` (turns) came after `robot sağa` (robot right) every time. The count is 2/2, so the probability of `döner` is 100 per cent. A word that was never seen has a probability of zero.

### Context length
The **bigram model** looks only at the last word; the **trigram model** looks at the last two words. Real counts taken from the corpus:

| Context | Model | Next words (count) | Total |
|---|---|---|---|
| `ve` (and) | bigram | `ileri` 4, `durur` 3, `sağa` 2, the others 1 each | 16 |
| `görür ve` (sees and) | trigram | `durur` 2, `sağa` 2, `geri` 1, `ileri` 1, `sola` 1 | 7 |

In the bigram model, `ileri` (forward) leads with 4/16 = 25%. In the trigram model the context `görür ve` is more specific: `durur` (stops) and `sağa` (right) come first with 2/7 = about 28.6%. A longer context narrows the prediction to what the context really says; but for that, the context must have appeared often enough in the corpus.

### Backing off
If the context does not appear in the corpus at all, the model cannot come out empty. First it looks at a shorter context (the last word); if that is missing too, it falls back on the general word frequencies in the corpus. The tool writes on the screen which level it used. This is called **backing off**.

### Generation and the seed
When it generates, the model makes a random choice based on the probabilities. This randomness comes from a **seed** number: the same context, the same setting and the same seed always give the same text. If you change the seed, the path splits. This is also useful for reproducing a mistake.

### The link with large models
The idea is the same: working out the probability of the next piece after a context. The difference is scale. A large language model does not keep a counting table; it sees a much longer context and gives the probability with a calculation it has learned. The tool here is a small example that makes the mechanism visible.

### Summary
A word's probability is the ratio of how many times it came after the context to the total. A trigram model uses more of the context than a bigram model but needs data; if the context is missing, the model backs off to a shorter context. The same seed produces the same text.
