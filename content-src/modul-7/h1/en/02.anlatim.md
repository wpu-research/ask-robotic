### What you will learn in this lesson
- What a token is, and why it is not the same as a word
- How a text is split into tokens and turned into numbers
- What changes the token count (number of merges, language)
- Why the token count matters

### What you should know first
What you learned in lesson 1 is enough: you need to know that a language model predicts the next **token**. All the tools named in this lesson run in the browser and their calculations are real.

### How does a model see text?
You read the sentence `robotlar duvarı görür` (robots see the wall) as three words. A language model sees it as pieces called **tokens**. A token is sometimes a whole word, sometimes part of a word, sometimes a single letter or punctuation mark. The model does not read text directly: first it splits it into pieces, then turns each piece into a whole number. What it predicts is really the next whole number.

```
text      :  robotlar duvarı
tokens    :  [▁robot] [l] [ar] [▁duvarı]
numbers   :  [ 118 ] [ 9 ] [ 41 ] [ 77 ]      (example values)
```

In this portal's tool, the space at the start of a word is shown with "·" or "▁". This way the word `robot` and a `robot` piece inside another word are kept apart.

### The pieces are not fixed
The same text takes up a different number of tokens depending on how big the tokeniser's "vocabulary" is. The **number of merges** in the tool sets this. With the Turkish corpus and the text `robot ileri` (robot forward):

| Number of merges | Tokens | Count |
|---|---|---|
| 0 | ▁ r o b o t ▁ i l e r i | 12 |
| Many | ▁robot ▁ileri | 2 |

At zero, every letter is a separate token, and the mark at the start of each word counts as a token too. That is why two words with 10 letters in total make 12 tokens.

### Language changes the token count
A tokeniser knows the pieces of the text it was trained on well. In the tool, with 120 merges, the sentence "the robot turns left" takes 4 tokens with the English corpus and 13 tokens with the Turkish corpus. A language seen less in training is split into smaller pieces. For Turkish, an agglutinative language, this is an important question.

### Why does the token count matter?
- A model can see only a certain number of tokens at once; in later lessons this is called the context window.
- In most model services, the number of tokens processed decides speed and cost.
- Working out "how many tokens?" by counting the words in a sentence gives the wrong result.

### Summary
A language model sees text as tokens, not words, and turns each token into a number. The same text takes up a different number of tokens depending on the tokeniser's vocabulary and language. You need to know the token count because it affects how much text a model can see and how much it costs. The tokeniser in the tool is a small example; real models' tokenisers are much bigger.
