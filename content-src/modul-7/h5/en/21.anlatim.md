### What you will learn in this lesson

- The difference between word count and TF-IDF
- How to work out the cosine similarity of two vectors by hand
- That the vectors in the workshop are real calculations, but carry no meaning

### What you should know first
Lesson 2 (tokens): splitting a text into pieces. Lesson 4 (next word): counting the words in a text. Beyond that, secondary-school multiplication, addition and square roots are enough.

### Why do we turn text into numbers?
A computer cannot read and understand the link between `ses dalgası` (sound wave) and `ultrasonik sensör` (ultrasonic sensor); but it can compare numbers. So we turn each text into a **vector**, that is, an ordered list of numbers. Each position in the list belongs to one term.

### Word count
The simplest method is to count how many times each term appears. The order of terms is: (`robot`, `sensör`, `motor`), where `sensör` means sensor.

```
A = "robot sensör"   ->  (1, 1, 0)
B = "robot motor"    ->  (1, 0, 1)
C = "robot sensör robot sensör" -> (2, 2, 0)
```

In the workshop the text is first lowercased, common linking words such as `ve` (and) and `bir` (a/one) are thrown away, and the first five letters of each word are kept. This is very simple stemming; it is not a real Turkish analyser.

### TF-IDF: a rare word is worth more
A word that appears in every document does not tell documents apart. **TF-IDF** multiplies the count by how rare the word is. In the workshop the weight is worked out with this formula:

```
idf = ln((n + 1) / (df + 1)) + 1
```

Here n is the number of documents and df is the number of documents the term appears in. In eight documents, `sensör` (sensor) appears in three: idf is about 1.81. `Servo` appears in one: idf is about 2.50. The rare word `servo` gets more weight.

### Cosine similarity
It is the cosine of the angle between two vectors:

```
similarity = (A · B) / (|A| × |B|)
```

In the example above, A · B = 1×1 + 1×0 + 0×1 = 1. |A| = √2, |B| = √2. Similarity = 1 / 2 = 0.5. A and C point the same way, so their similarity is 1; length makes no difference. If there are no shared terms, every product is 0 and the similarity is 0.

### Summary
A text is turned into a vector made of term counts. TF-IDF gives more weight to rare terms. Cosine similarity looks at the direction of two vectors: it comes out 0 if there are no shared terms and 1 if they point the same way. The calculations in the workshop are real; but these are word vectors, not meaning.
