### What you will learn in this lesson
- What a single accuracy number can hide
- How to work out recall for a label
- Why a system that always gives the same answer gets a high accuracy on an unbalanced set
- How to group mistakes by their causes

### What you should know first
Lesson 16 (accuracy = correct / total) and lesson 17 (three labels, a balanced set). Percentage sums and simple division are enough.

### Accuracy on its own is not enough
You have 100 comments: 90 positive, 10 negative. The system looks at nothing and says "positive" to every comment. What is its accuracy? 90 / 100 = 90%. It looks like a good number, but the system cannot find a single negative comment. The number is correct, but the conclusion is wrong.

### Looking per label: recall
For each expected label we ask: "How many of the cases with this label were found correctly?" This rate is called **recall**:

```
recall(label) = cases of that label found correctly / all cases of that label
```

In the system that always says "positive", the recall for positive is 90 / 90 = 100%, but for negative it is 0 / 10 = 0%. The per-label table reveals the weakness that the single number hides. Careful: the bottom of the fraction is not all the cases, only the cases of that label.

### A small example
In a set of five cases, the system did this:

```
"Berbat bir ders"       negative  ->  negative  (correct)
"Harika, yine bozuldu"  negative  ->  positive  (wrong)
"Çok yavaş"             negative  ->  negative  (correct)
"Fena değil"            positive  ->  unclear   (wrong)
"Güzel"                 positive  ->  positive  (correct)
```

(In English: "An awful lesson", "Great, it broke again", "Very slow", "Not bad", "Nice".)

The overall accuracy is 3 / 5 = 60%. The recall for negative is 2 / 3, and for positive 1 / 2.

### Group the mistakes
Instead of patching the wrong cases one by one, group them by their shared cause. If two mistakes come from sarcasm and one from an unknown word, there are two groups. Finding and fixing the cause of a group can solve all the cases in that group at once.

### Not every mistake costs the same
In the robot example, saying "continue" at an obstacle is much more dangerous than saying "stop" for no reason. Knowing which mistake is more costly decides which label you pay more attention to.

### Summary
Accuracy on its own can mislead, especially if the labels are unbalanced. Recall tells you how many of the cases with a label were found correctly, and shows the weak point. Grouping mistakes by their causes speeds up fixing; different kinds of mistakes can have different costs.
