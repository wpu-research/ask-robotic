### What you will learn in this lesson
- How to make the program decide with `if`, `else if` and `else`
- The difference between comparison (`==`, `!=`, `<`, `>`) and assignment (`=`)
- How to combine several conditions with `&&`, `||` and `!`
- How to choose between many paths with `switch`, `case` and `break`

### What you should know first
`digitalRead`, `INPUT_PULLUP` and "pressed = LOW" from lesson 6; `digitalWrite` from lesson 3; `loop()` from lesson 1.

### The program decides
Until now every line of the program has run in order, without conditions. Real jobs need choices such as "if the button is pressed, switch the LED on; otherwise switch it off". You do this with **if**: if the condition is true, the code inside `{ }` runs; otherwise the `else` part runs.

```
if (digitalRead(2) == LOW) {
  digitalWrite(13, HIGH);
} else {
  digitalWrite(13, LOW);
}
```

If there are three or more possibilities, you add `else if` in between. The chain checks from top to bottom, runs the code of the **first true** condition and does not look at the rest at all. That is why the order of the conditions matters: if `x > 3` is written first, the `x > 5` condition never gets its turn.

### Comparison and assignment
Inside a condition you compare values: `==` equal?, `!=` not equal?, `<`, `>`, `<=`, `>=`. The most common mistake is writing a single `=` instead of `==`. A single `=` is an **assignment**: it puts the value on the right into the variable and gives that value itself as the result. If you write `if (durum = LOW)`, durum becomes 0 every time, the condition always counts as false and the program quietly does the wrong thing.

### Logic operators
To combine two conditions there are logic operators. Let `a` and `b` be two pieces of state information (for example whether two buttons are pressed). These are variables of type **bool**, which means they hold only `true` or `false`.

| a | b | a && b (and) | a \|\| b (or) | !a (not) |
|---|---|---|---|---|
| false | false | false | false | true |
| false | true | false | true | true |
| true | false | false | true | false |
| true | true | true | true | false |

`&&` is true only if both sides are true; `||` is true if at least one is true. `!` turns true into false and false into true. `digitalWrite` accepts a `bool` value: true becomes HIGH and false becomes LOW.

### Choosing between many paths with switch
If you are going to split into many paths depending on the same variable, `switch` keeps things tidy. First you can turn the state of the two buttons into a single number: the first button gives 1 point and the second gives 2 points; the total is 0, 1, 2 or 3. Then `switch (kod)` jumps to the matching `case` line. Every `case` needs a **break** at the end; otherwise the program runs the code of the next `case` too (this is called "falling through"). If no `case` matches, `default` runs.

### Summary
`if/else if/else` makes the program decide; in a chain, the first true condition wins. Use `==` to compare and `=` to assign; mixing them up leads to quiet bugs. `&&`, `||` and `!` combine conditions. `switch` writes a choice between many paths neatly, but every `case` needs a `break` at the end.
