### Writing the same code again and again
If you write the three lines "play a note, wait" twenty times in a melody, the program gets long. If you make a mistake, you fix twenty places one by one. A **function** lets you give a group of commands a name and run it as many times as you like. In fact, `setup()` and `loop()` are functions too.

### The parts of a function
```
int vurusSuresi(int bpm) {
  return 60000 / bpm;
}
```

| Part | Meaning |
|---|---|
| `int` | **Return type**: the function gives back a whole number. If it gives back nothing, you write `void`. |
| `vurusSuresi` | The function's name (beat length); it should say what the function does. |
| `(int bpm)` | **Parameter**: information given to the function from outside. |
| `{ ... }` | Body: the commands that will run. |
| `return` | Gives the result back to the caller. |

Writing a function does not run it. To make it run, you must **call** it by its name: `vurusSuresi(120);` Here `bpm` becomes 120 and the result is 60000 / 120 = 500 ms. A function can also call other functions: `melodiCal` calls `notaCal` for every note.

### Scope: where does a variable live?
**Scope** is which parts of the code can see a variable.

| Type | Where it is defined | What it is like |
|---|---|---|
| Local | Inside the function | Only that function sees it; it is created afresh on every call |
| Global | Outside all functions | Everyone sees it; its value is kept between calls |

If you use a local variable in another function, the compiler gives the error "was not declared in this scope".

### A parameter is a copy
When you give a variable to a function, the function works with its **copy**:

```
void ikiyeKatla(int x) {
  x = x * 2;     // only the copy changes
}
// if sayi = 5, sayi is still 5 after ikiyeKatla(sayi)
```

If you want to change the value outside, you use a global variable or take the result back with `return`: `sayi = ikiyeKatla(sayi);`. If you write `const` in front of numbers that never change (such as the buzzer pin), you cannot change them by mistake.

### Summary
A function gives a group of commands a name so you can use it again and again. Defining it does not run it; you must call it by its name. Parameters carry information in from outside, and `return` gives the result back. A local variable lives only in its own function; a global variable is seen everywhere. Because a parameter is a copy, a change inside the function does not affect the outside.
