# LCD 16x2 ekran
süre: 20

## Merak
Şimdiye kadar kartın söylediklerini Serial Monitor'de okudun. Ama bir termostatın başına bilgisayar götürmezsin. Cihazın kendi küçük ekranında "Sıcaklık: 23.5 C" yazsa nasıl olurdu? Üstelik bunu yalnızca birkaç satır kodla yapabilirsin.

## Etkinlik
### Devre
16x2 LCD, her biri 16 karakter alan iki satırdan oluşur. Çoğu modül HD44780 denetleyicili çiptir. Uno ile **4 bitlik** kipte konuşmak için 6 sinyal pini yeter: RS, E ve D4-D7.

Parçaları laboratuvarda **Parça ekle** menüsünden seç, pinleri kablo çekerek bağla. Gereken parçalar: `lcd1602` ekran, bir potansiyometre (kontrast için) ve bir 220 Ω direnç (arka ışık için).

| Parça | Bağlantı |
|---|---|
| LCD VSS, RW ve K | GND |
| LCD VDD | 5V |
| LCD A (arka ışık +) | 220 Ω direnç üzerinden 5V |
| LCD V0 (kontrast) | Potansiyometrenin SIG ucu (potansiyometrenin VCC ucu 5V'a, GND ucu GND'ye) |
| LCD RS | **D12** |
| LCD E | **D11** |
| LCD D4 | **D5** |
| LCD D5 | **D4** |
| LCD D6 | **D3** |
| LCD D7 | **D2** |

LCD'nin D0-D3 uçları boş kalır. Laboratuvar ekranı şöyle modeller: yazı görünmesi için VDD en az 4 V olmalı, VSS ve RW toprağa bağlı olmalı. **V0 gerilimi yaklaşık 1,6 V'u aşarsa ekran boş kalır**; V0 hiç bağlı değilse yazı görünür. Potansiyometrenin varsayılan konumu 0,5'tir (V0 = 2,5 V), yani ilk başta ekran boş görünür. Çalışırken potansiyometreyi seçip **Konum** değerini 0,3'ün altına indir ya da V0 pinini seçip **Sanal ölçüm** ile gerilimine bak. Arka ışık A ve K uçlarından akım (1 mA'den fazla) geçince yanar; ışık yanmasa bile yazı görünebilir.

### Program
```cpp
// sketch: lcd_merhaba
#include <LiquidCrystal.h>

// Sıra: RS, E, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);          // 16 sütun, 2 satır
  lcd.print("Merhaba!");     // 1. satır, 1. sütundan başlar
  lcd.setCursor(0, 1);       // sütun 0, satır 1 (alt satır)
  lcd.print("Saniye:");
}

void loop() {
  lcd.setCursor(8, 1);               // sayıyı sabit yere yaz
  lcd.print(millis() / 1000);
}
```

### Nasıl çalışıyor?
1. `#include <LiquidCrystal.h>` kütüphaneyi programa ekler. Kütüphane, ekranla konuşmanın zor ayrıntılarını senin yerine halleder.
2. `LiquidCrystal lcd(12, 11, 5, 4, 3, 2);` bir **nesne** oluşturur. Parantez içindeki sayılar bağlantı pinleridir: önce RS, sonra E, sonra D4'ten D7'ye.
3. `lcd.begin(16, 2)` ekranın boyutunu söyler ve ekranı başlatır. Bunu `setup` içinde bir kez çağırırsın.
4. `lcd.print(...)` yazıyı imlecin bulunduğu yere yazar. Sayı da verebilirsin; `Serial.print` ile aynı biçimde çalışır.
5. `lcd.setCursor(sütun, satır)` imleci taşır. Sayma 0'dan başlar: sol üst köşe `(0, 0)`, sağ alt köşe `(15, 1)`.
6. `loop` içinde sayıyı hep aynı yere yazıyoruz; böylece ekran yanıp sönmeden güncellenir.

**Eski yazıyı temizleme.** Ekranda "100" yazılıyken yerine "99" yazarsan "990" görürsün; çünkü LCD eski karakteri silmez, üzerine yazar. İki çözüm var:
- Her yazıdan önce `lcd.clear()` çağırmak (ekran titreyebilir).
- Yeni yazıyı boşluklarla tamamlamak: `lcd.print("99 ");`

**Özel karakter.** Ekran her karakteri 5x8 noktadan çizer. Derece işareti gibi kendi simgeni tanımlayabilirsin:

```cpp
// sketch: lcd_derece
#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

byte derece[8] = {
  0b00110,
  0b01001,
  0b01001,
  0b00110,
  0b00000,
  0b00000,
  0b00000,
  0b00000
};

void setup() {
  lcd.begin(16, 2);
  lcd.createChar(0, derece);       // 0 numaralı özel karakter yuvasına kaydet
  lcd.clear();                     // imleci ekran belleğine (DDRAM) döndür; yoksa yazı karakter belleğine gider
  lcd.print("Sicaklik: 23.5");
  lcd.write(byte(0));              // özel karakteri ekrana yaz
  lcd.print("C");
}

void loop() {
}
```

Her satır karakterin bir sırasıdır; `1` olan bit yanık noktadır. Yuva numarası 0-7 arasındadır; yani en fazla 8 özel karakter tanımlayabilirsin.

**Dikkat:** `createChar` çağrısından sonra mutlaka `lcd.clear()` ya da `lcd.setCursor(...)` çağır. HD44780'de `createChar` imleci karakter belleğine (CGRAM) taşır; arkasından gelen `print` yazıyı ekran belleğine değil bu belleğe yazar, ekran boş kalır. Bu davranış gerçek ekranda da aynıdır, laboratuvar da bunu modeller.

### Dene
- Üst satıra adını, alt satıra yaşını yazdır.
- `lcd.print(millis() / 1000)` satırında sayıyı 9'dan 10'a geçerken izle. Yazıyı hep aynı yerden başlattığın için bir sorun çıkıyor mu?
- `lcd.scrollDisplayLeft()` komutunu `loop` içinde `delay(300)` ile çağır. Yazı ne yapıyor?

### Sık yapılan hatalar
- Pin sırasını ya da kablolarını karıştırmak: `LiquidCrystal lcd(12, 11, 5, 4, 3, 2)` içindeki sıra RS, E, D4, D5, D6, D7'dir. Kodla kablolar uyuşmazsa ekran boş ya da anlamsız karakter gösterir.
- Kontrastı yanlış ayarlamak: V0 gerilimi yüksekse (laboratuvarda yaklaşık 1,6 V üstü) ekran boştur. Önce potansiyometre konumunu düşür.
- VDD, VSS ya da RW'yi bağlamamak: ekran açılmaz ya da yazı görünmez. RW'yi mutlaka GND'ye bağla.
- `createChar`'dan sonra `clear()` ya da `setCursor()` çağırmamak: yazı ekranda görünmez.
- `lcd.begin(16, 2)` satırını unutmak: ekran başlatılmaz.
- Türkçe karakterler (ı, ş, ğ) ekranın karakter tablosunda yoktur; yazılarda `i, s, g` kullan.
- Ekrana 16 karakterden uzun yazı yazmak: fazla kısım ekranda görünmez.
