# LCD 16x2 ekran
süre: 20

## Merak
Şimdiye kadar kartın söylediklerini Serial Monitor'de okudun. Ama bir termostatın başına bilgisayar götürmezsin. Cihazın kendi küçük ekranında "Sıcaklık: 23.5 C" yazsa nasıl olurdu? Üstelik bunu yalnızca birkaç satır kodla yapabilirsin.

## Etkinlik
### Devre
16x2 LCD, her biri 16 karakter alan iki satırdan oluşur. Çoğu modül HD44780 denetleyicili çiptir. Kartla **4 bitlik** kipte konuşmak için 6 sinyal pini yeter: RS, E ve D4-D7.

| LCD pini | Bağlantı |
|---|---|
| VSS (1), RW (5), K (16) | GND |
| VDD (2), A (15, arka ışık +) | 5 V (A için 220 Ω direnç önerilir) |
| V0 (3, kontrast) | 10 kΩ potansiyometrenin orta ucu (diğer uçlar 5 V ve GND) |
| RS (4) | **D12** |
| E (6) | **D11** |
| D4 (11) | **D5** |
| D5 (12) | **D4** |
| D6 (13) | **D3** |
| D7 (14) | **D2** |

D0-D3 pinleri (7-10) boş kalır. Ekranda yazı görünmüyorsa önce kontrast potansiyometresini çevir.

### Program
```cpp
// sketch: lcd_merhaba
#include <LiquidCrystal.h>

// Sıra: RS, E, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);          // 16 sütun, 2 satır
  lcd.print("Merhaba!");     // 1. satır, 1. sütundan başlar
  lcd.setCursor(0, 1);       // sütun 0, satır 1 (alt satır)
  lcd.print("Saniye:");
}

void loop() {
  lcd.setCursor(8, 1);               // sayıyı sabit yere yaz
  lcd.print(millis() / 1000);
}
```

### Nasıl çalışıyor?
1. `#include <LiquidCrystal.h>` kütüphaneyi programa ekler. Kütüphane, ekranla konuşmanın zor ayrıntılarını senin yerine halleder.
2. `LiquidCrystal lcd(12, 11, 5, 4, 3, 2);` bir **nesne** oluşturur. Parantez içindeki sayılar bağlantı pinleridir: önce RS, sonra E, sonra D4'ten D7'ye.
3. `lcd.begin(16, 2)` ekranın boyutunu söyler ve ekranı başlatır. Bunu `setup` içinde bir kez çağırırsın.
4. `lcd.print(...)` yazıyı imlecin bulunduğu yere yazar. Sayı da verebilirsin; `Serial.print` ile aynı biçimde çalışır.
5. `lcd.setCursor(sütun, satır)` imleci taşır. Sayma 0'dan başlar: sol üst köşe `(0, 0)`, sağ alt köşe `(15, 1)`.
6. `loop` içinde sayıyı hep aynı yere yazıyoruz; böylece ekran yanıp sönmeden güncellenir.

**Eski yazıyı temizleme.** Ekranda "100" yazılıyken yerine "99" yazarsan "990" görürsün; çünkü LCD eski karakteri silmez, üzerine yazar. İki çözüm var:
- Her yazıdan önce `lcd.clear()` çağırmak (ekran titreyebilir).
- Yeni yazıyı boşluklarla tamamlamak: `lcd.print("99 ");`

**Özel karakter.** Ekran her karakteri 5x8 noktadan çizer. Derece işareti gibi kendi simgeni tanımlayabilirsin:

```cpp
// sketch: lcd_derece
#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

byte derece[8] = {
  0b00110,
  0b01001,
  0b01001,
  0b00110,
  0b00000,
  0b00000,
  0b00000,
  0b00000
};

void setup() {
  lcd.begin(16, 2);
  lcd.createChar(0, derece);       // 0 numaralı özel karakter yuvasına kaydet
  lcd.print("Sicaklik: 23.5");
  lcd.write(byte(0));              // özel karakteri ekrana yaz
  lcd.print("C");
}

void loop() {
}
```

Her satır karakterin bir sırasıdır; `1` olan bit yanık noktadır. Yuva numarası 0-7 arasındadır; yani en fazla 8 özel karakter tanımlayabilirsin.

### Dene
- Üst satıra adını, alt satıra yaşını yazdır.
- `lcd.print(millis() / 1000)` satırında sayıyı 9'dan 10'a geçerken izle. Yazıyı hep aynı yerden başlattığın için bir sorun çıkıyor mu?
- `lcd.scrollDisplayLeft()` komutunu `loop` içinde `delay(300)` ile çağır. Yazı ne yapıyor?

### Sık yapılan hatalar
- Pin sırasını karıştırmak: `LiquidCrystal lcd(12, 11, 5, 4, 3, 2)` içindeki sıra RS, E, D4, D5, D6, D7'dir. Yanlış sıra boş ya da anlamsız karakter gösterir.
- Kontrast ayarını yapmamak: ekran yanık görünür ama yazı yoktur (ya da tüm kutular dolu görünür).
- `lcd.begin(16, 2)` satırını unutmak: ekran başlatılmaz.
- Türkçe karakterler (ı, ş, ğ) ekranın karakter tablosunda yoktur; yazılarda `i, s, g` kullan.
- Ekrana 16 karakterden uzun yazı yazmak: fazla kısım ekranda görünmez.
