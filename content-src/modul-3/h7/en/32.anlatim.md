### What you will learn in this lesson
- The layout of a 16x2 LCD (2 rows, 16 characters per row) and which 6 signal pins it uses in four-bit mode
- Creating an object and starting the display with the `LiquidCrystal` library
- Writing anywhere you like on the display with `print`, `setCursor` and `clear`
- Getting to know the contrast pin (V0) and custom characters

### What you should know first
Printing with `Serial.print` from lesson 9; setting a voltage with a potentiometer from lesson 11; the pin shortage caused by connections with many pins from lesson 31.

### How to think about a character display
A 16x2 LCD is a grid of 2 rows with 16 boxes in each row. One character is written into each box. The boxes are drawn from 5x8 dots. Text goes where the **cursor** is, just like text in the serial monitor. Counting starts from 0:

```
column: 0  1  2 ... 15
row 0   [ ][ ][ ]...[ ]
row 1   [ ][ ][ ]...[ ]
```

The top left corner is `(0, 0)` and the bottom right corner is `(15, 1)`. `lcd.setCursor(sütun, satır)` moves the cursor; you write the column first, then the row.

### Connection: 6 signals, 2 power groups
Most displays work with the HD44780 controller. In four-bit mode the signal pins are **RS** (command or data), **E** (enable) and **D4-D7** (data). The RW pin is connected to GND, because we do not read from the display. VDD goes to 5V and VSS to GND. The backlight is powered through the A and K pins with a resistor.

The **V0** pin sets the contrast. It is usually adjusted between 0 and 5 V with a potentiometer. If the voltage is too high, the display looks blank. In this lab model the display is blank if V0 goes above about 1.6 V.

### The library and the object
```
#include <LiquidCrystal.h>
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);   // RS, E, D4, D5, D6, D7

void setup() {
  lcd.begin(16, 2);
  lcd.print("Merhaba");
}
```
The **order** of the numbers in the brackets is RS, E, D4, D5, D6, D7. If the wires and the code do not match, the display looks blank or garbled. `lcd.begin(16, 2)` starts the display and tells it its size; if you forget it, the display does not work.

### Text is not deleted, it is written over
The LCD does not delete an old character by itself. If the display shows `250` and you write `7` in the same place, you see `750`. Two solutions: deleting everything with `lcd.clear()` (the display may flicker) or padding the new text with spaces, for example `lcd.print("7  ")`.

### Custom character
Every character is made of dots in 5 columns and 8 rows. Each row is a 5-bit number, and a bit that is `1` is a lit dot. With `lcd.createChar(yuva, dizi)` (slot, array) you define at most 8 custom characters, numbered 0-7. After defining them you must call `lcd.clear()` or `lcd.setCursor()`; otherwise the text goes into the character memory instead of the display memory, and the display stays blank. The display's character table does not have Turkish letters such as `ı`, `ş`, `ğ`.

### Summary
Writing to the LCD takes three steps: add the library and create the object with the right pin order, start it with `begin(16, 2)`, and write with `setCursor` and `print`. Because old text is not deleted, clear the area you will write over when updating, or fill it with spaces. If the display is blank, check the contrast setting (V0) first.
