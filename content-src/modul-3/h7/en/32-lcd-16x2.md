# The 16x2 LCD display
duration: 20

## Wonder
Until now you have read what the board says in the Serial Monitor. But you would not carry a computer to a thermostat. How would it be if the device wrote "Temperature: 23.5 C" on its own small screen? And you can do this with only a few lines of code.

## Activity
### Circuit
A 16x2 LCD is made of two rows, each holding 16 characters. Most modules are chips with an HD44780 controller. To talk to the Uno in **4-bit** mode, 6 signal pins are enough: RS, E and D4-D7.

Pick the parts from the **Add part** menu in the lab and connect the pins by drawing wires. Parts you need: an `lcd1602` display, a potentiometer (for contrast) and a 220 Ω resistor (for the backlight).

| Part | Connection |
|---|---|
| LCD VSS, RW and K | GND |
| LCD VDD | 5V |
| LCD A (backlight +) | 5V through a 220 Ω resistor |
| LCD V0 (contrast) | The potentiometer's SIG pin (the potentiometer's VCC pin to 5V, its GND pin to GND) |
| LCD RS | **D12** |
| LCD E | **D11** |
| LCD D4 | **D5** |
| LCD D5 | **D4** |
| LCD D6 | **D3** |
| LCD D7 | **D2** |

The LCD's D0-D3 pins stay unconnected. The lab models the display like this: for text to appear, VDD must be at least 4 V, and VSS and RW must be connected to ground. **If the V0 voltage goes above about 1.6 V, the display stays blank**; if V0 is not connected at all, the text is visible. The potentiometer's default position is 0.5 (V0 = 2.5 V), so at first the display looks blank. While it runs, select the potentiometer and lower its **Position** value below 0.3, or select the V0 pin and look at its voltage with the **Virtual meter**. The backlight lights up when current (more than 1 mA) flows through the A and K pins; the text can be visible even when the light is off.

### Program
```cpp
// sketch: lcd_merhaba
#include <LiquidCrystal.h>

// Sıra: RS, E, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);          // 16 sütun, 2 satır
  lcd.print("Merhaba!");     // 1. satır, 1. sütundan başlar
  lcd.setCursor(0, 1);       // sütun 0, satır 1 (alt satır)
  lcd.print("Saniye:");
}

void loop() {
  lcd.setCursor(8, 1);               // sayıyı sabit yere yaz
  lcd.print(millis() / 1000);
}
```

### How does it work?
1. `#include <LiquidCrystal.h>` adds the library to the program. The library handles the hard details of talking to the display for you.
2. `LiquidCrystal lcd(12, 11, 5, 4, 3, 2);` creates an **object**. The numbers in the brackets are the connection pins: first RS, then E, then D4 to D7.
3. `lcd.begin(16, 2)` tells the display its size and starts it. You call this once inside `setup`.
4. `lcd.print(...)` writes text where the cursor is. You can give it a number too; it works the same way as `Serial.print`.
5. `lcd.setCursor(sütun, satır)` moves the cursor (column, row). Counting starts from 0: the top left corner is `(0, 0)`, the bottom right corner is `(15, 1)`.
6. In `loop` we always write the number in the same place; this way the display updates without flickering.

**Clearing old text.** If the display shows "100" and you write "99" in its place, you see "990"; the LCD does not delete the old character, it writes over it. There are two solutions:
- Calling `lcd.clear()` before every write (the display may flicker).
- Padding the new text with spaces: `lcd.print("99 ");`

**Custom character.** The display draws every character from 5x8 dots. You can define your own symbol, such as a degree sign:

```cpp
// sketch: lcd_derece
#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

byte derece[8] = {
  0b00110,
  0b01001,
  0b01001,
  0b00110,
  0b00000,
  0b00000,
  0b00000,
  0b00000
};

void setup() {
  lcd.begin(16, 2);
  lcd.createChar(0, derece);       // 0 numaralı özel karakter yuvasına kaydet
  lcd.clear();                     // imleci ekran belleğine (DDRAM) döndür; yoksa yazı karakter belleğine gider
  lcd.print("Sicaklik: 23.5");
  lcd.write(byte(0));              // özel karakteri ekrana yaz
  lcd.print("C");
}

void loop() {
}
```

Each line is one row of the character; a bit that is `1` is a lit dot. The slot number is between 0 and 7, so you can define at most 8 custom characters.

**Careful:** after calling `createChar`, always call `lcd.clear()` or `lcd.setCursor(...)`. On the HD44780, `createChar` moves the cursor to the character memory (CGRAM); a `print` that comes after it writes the text into that memory instead of the display memory, and the display stays blank. A real display behaves the same way, and the lab models it too.

### Try it
- Print your name on the top row and your age on the bottom row.
- On the `lcd.print(millis() / 1000)` line, watch the number as it goes from 9 to 10. Is there a problem, since you always start the text from the same place?
- Call the `lcd.scrollDisplayLeft()` command inside `loop` with `delay(300)`. What does the text do?

### Common mistakes
- Mixing up the pin order or the wires: the order inside `LiquidCrystal lcd(12, 11, 5, 4, 3, 2)` is RS, E, D4, D5, D6, D7. If the code and the wires do not match, the display shows nothing or meaningless characters.
- Setting the contrast wrongly: if the V0 voltage is high (in the lab, above about 1.6 V), the display is blank. Lower the potentiometer position first.
- Not connecting VDD, VSS or RW: the display does not turn on or the text does not show. Always connect RW to GND.
- Not calling `clear()` or `setCursor()` after `createChar`: the text does not appear on the display.
- Forgetting the `lcd.begin(16, 2)` line: the display is not started.
- Turkish letters (`ı`, `ş`, `ğ`) are not in the display's character table; use `i, s, g` in your text.
- Writing text longer than 16 characters: the extra part does not appear on the display.
