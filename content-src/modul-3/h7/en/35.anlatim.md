### The three parts of the system
The thermostat repeats this cycle: **measure, decide, act**. The measurement comes from the divider made of the NTC and the fixed resistor. From the ADC value on A2, the NTC's resistance is found with `R = 10000 × ADC / (1023 − ADC)`, and the β = 3950 formula turns it into a temperature. As the temperature rises, the NTC's resistance falls and the ADC value gets smaller. For example, ADC = 400 means about 35.3 °C. The decision is in the state machine. The action is the relay on D7.

### Hysteresis: two thresholds
If you use a single threshold ("with the target at 22 °C, switch on below 22 and off above it"), the relay switches on and off many times a second when the temperature wobbles around 22. This both ends the relay's life and wears out the heater. The solution is two thresholds:

```
switch-on threshold  = target − 0.5   (21.5 for 22)
switch-off threshold = target + 0.5   (22.5 for 22)
```

When the temperature falls below 21.5, the heater switches on and stays on until it reaches 22.5. In the 1-degree zone in between, the relay **keeps its previous state**. This gap is called hysteresis.

### State machine
| State | Relay | Leaving condition |
|---|---|---|
| `KAPALI` (off) | Off | if temperature ≤ target − 0.5, `ISITIYOR`; if a button is pressed, `AYAR` |
| `ISITIYOR` (heating) | On | if temperature ≥ target + 0.5, `KAPALI`; if a button is pressed, `AYAR` |
| `AYAR` (setting) | Off | 2 seconds after the last press the target is written, `KAPALI` |

The relay output is worked out from the state: HIGH if `ISITIYOR`, otherwise LOW. This makes it hard to leave the relay in the wrong state.

### Saving the setting
If you write to the EEPROM on every button press, adjusting the setting uses up its lifetime. Instead, each press only restarts the 2-second timer; when the time is up, the target is written once with `EEPROM.update`. Six presses also turn into a single write, and if the target has not changed at all, nothing is written. If the value read at start-up is not between 10 and 35 (for example 255 from an empty EEPROM), the default of 22 is used.

### Thinking about safety
If the sensor comes loose, the A2 pin is pulled to 5 V and the ADC gets close to its highest value; the program takes this as very cold and the heater stays on all the time. On a real heater this is dangerous. That is why a check of "is the reading in a sensible range?" and adult supervision are a must. In this lesson you use an LED instead of a heater.

### Summary
The thermostat is made of an NTC measurement, a state machine with hysteresis and a relay output. The two thresholds stop the relay from chattering, `millis()` means the program never waits, and the EEPROM keeps the target when the power is cut. You write the setting only once, when the time is up, and you think about sensor failure separately.
