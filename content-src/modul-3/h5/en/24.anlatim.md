### Safety comes first
On this portal you only work with the Uno's 5 V. In real life, **mains voltage (220 V)** can kill; controlling a device that is plugged into a socket with a relay is a job for a trained specialist. A module having "250 V" printed on it does not mean you can use it safely.

### What is a relay?
A relay is a switch that works with an electromagnet. When current flows through the coil, the magnet pulls an arm and the contacts change position. The coil side and the contact side are electrically separate; the contact side simply behaves like a switch (a **dry contact**).

```
COM  common terminal
NO   normally open:   open when not energised,          connected to COM when energised
NC   normally closed: connected to COM when not energised, opens when energised
```

The module already has the transistor and diode that drive the coil; you only connect VCC, GND and IN.

### Active-LOW
Most modules pull in when the IN pin gets **LOW** and release when it gets HIGH. So the "off" state is HIGH. To stop the relay clicking for a moment at start-up, you write `digitalWrite(ROLE, HIGH)` before `pinMode`.

### Hysteresis
If a value such as temperature wobbles around a single threshold, the relay clicks all the time and its mechanical contacts wear out. The solution is two thresholds.

```
if value > 600  energise
if value < 500  release
between 500-600: stay as it is
```

This 100-unit range is called **hysteresis**. Because a relay is mechanical, it is not suitable for fast PWM; for speed control, use a transistor or a MOSFET.

### Summary
A relay is an electromagnetic switch that switches a separate circuit on and off with a low-current signal. The load goes between COM and NO or NC. Most modules are energised by LOW. Hysteresis prevents chattering around the threshold. Mains voltage belongs only to a specialist.
