### Why does a servo "go to an angle"?
An ordinary DC motor turns as long as you give it power; it does not know how far it has turned. A **servo**, however, holds a motor, a set of gears and a sensor that measures the angle of its shaft. Its small built-in controller compares the requested angle with the measured angle and drives the motor until the difference is zero. That is why, when a servo gets the command "37 degrees", it goes there and stays.

### The angle is given by the pulse width
A servo has three wires: VCC (5 V), GND and SIG (signal). The **width** of the pulse arriving on the SIG wire sets the angle. The pulse repeats every 20 ms; what matters is how long the pulse lasts.

```
Angle   Pulse width
0 °     ~544 µs
90 °    ~1472 µs
180 °   ~2400 µs
```

The angles in between are linear: about (2400 − 544) / 180 ≈ 10.3 µs is added per degree. For example, 45 degrees needs 544 + 45 × 10.31 ≈ 1008 µs. The `Servo` library makes these pulses for you; you only write the angle.

### Three commands are enough
```
#include <Servo.h>
Servo servom;          // servo object
servom.attach(9);      // signal wire on D9
servom.write(90);      // go to 90 degrees
```
If you do not write `attach`, no pulses are made and the servo does not move. `write` only takes angles from 0 to 180. The servo does not teleport; turning takes time, so in a sweep we put a short `delay` after each step. The longer the wait, the slower the sweep: 181 steps × 15 ms ≈ 2.7 seconds.

### Setting the angle with a potentiometer
`analogRead` gives 0-1023, but the servo wants 0-180. `map(okuma, 0, 1023, 0, 180)` converts the range. Because `map` uses integer maths, the result is rounded down. The Servo library switches off the `analogWrite` (PWM) feature on D9 and D10; do not expect PWM from these two pins.

### Summary
A servo learns the requested angle from the width of a pulse that repeats every 20 ms: 544 µs is 0 degrees, 2400 µs is 180 degrees. You name the pin with `attach` and give the angle with `write`. To drive it with a potentiometer, you use `map`. The servo's power comes from 5V and GND, and its command comes from the SIG wire.
