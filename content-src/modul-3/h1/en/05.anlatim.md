### What you will learn in this lesson
- How to start a project with a **plan**, not with code
- How to put the stages into a table (which LED, for how long)
- How to build the traffic light circuit and program
- How to combine what you learnt in earlier lessons in a single project

### What you should know first
`pinMode`, `digitalWrite`, `delay` (lesson 3), a series resistor for each LED (lesson 2), connecting several LEDs (lesson 4). Arrays and loops are optional in this lesson.

### The plan comes before the code
Even a small project is made of several steps. If you jump straight into code, you get confused while writing which LED should be on when. First draw a **table**:

| Stage | LED that is on | Time |
|---|---|---|
| 1 | Red (D13) | 5 seconds |
| 2 | Green (D11) | 5 seconds |
| 3 | Yellow (D12) | 2 seconds |

Once the table is right, the code becomes a line-by-line translation of the table.

### From the table to the code
In the code, each stage is made of the same three steps:
1. **Switch off** the LEDs that should not be on (`LOW`).
2. **Switch on** the LED that should be on (`HIGH`).
3. **Wait** for the stage's time (`delay`).

If you forget to switch off the previous LED in a stage, two LEDs are on together. At a real junction, both directions being green together would cause an accident.

### Write the times correctly
`delay` takes **milliseconds**. For 5 seconds you write `delay(5000)`. `delay(5)` waits for only 5 milliseconds. The time for the whole round is the total of the stage times: 5 + 5 + 2 = 12 seconds.

### Circuit
Each LED has its own series resistor. For the red LED, about 9 mA flows with 330 Ω at 5 V (lesson 2). The yellow and green LEDs have a slightly different voltage drop; the same resistor is a safe choice.

### Summary
Project = plan + circuit + code. Write the table first, then turn each stage into code with the "switch off, switch on, wait" pattern. Do not forget to convert the times to milliseconds and to switch off the previous LED.
