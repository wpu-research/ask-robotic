### What you will learn in this lesson
- How to repeat a job with a `for` loop instead of writing it again and again
- How to keep several values under one name with arrays and reach the elements by number
- How to light four LEDs in turn
- How to recognise loop and array mistakes

### What you should know first
Lesson 3: `pinMode`, `digitalWrite`, `delay`, building a circuit. Lesson 2: each LED has its own series resistor.

### A job that repeats
To light four LEDs in turn, you have to write the same three lines four times. With thirty LEDs, you would write ninety lines. Programmers leave jobs like this to the computer: "Repeat these steps this many times."

### The for loop
`for` works with three parts:

```
for (int i = 10; i <= 13; i++) {
  // body: i becomes 10, 11, 12, 13 in turn
}
```

1. **Start** (`int i = 10`): the counter is set up once, before the loop begins.
2. **Condition** (`i <= 13`): checked before each round; if it is true, the body runs; if it is false, the loop ends.
3. **Step** (`i++`): after each round, the counter goes up by 1. `i--` takes 1 off instead.

In this example the body runs for i = 10, 11, 12 and 13, so **4 rounds**. When i becomes 14, the condition is false and the loop ends.

### Array
An **array** stores many values of the same type under a single name:

```
int ledler[] = {13, 12, 11, 10};
```

You reach the elements **by number (index)**, and the numbering **starts from 0**:

| Index | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Value | 13 | 12 | 11 | 10 |

The value of `ledler[2]` is 11. In a 4-element array the valid indexes are 0, 1, 2 and 3; `ledler[4]` **goes past the end** of the array and leads to unexpected behaviour.

### Loop and array together
If you walk through the array with `for`, you write the same code only once for every LED:

```
for (int i = 0; i < 4; i++) {
  digitalWrite(ledler[i], HIGH);
}
```

`i < 4` and `i <= 3` give the same result. If the number of elements is N, an array loop usually uses `i < N`. The pin numbers do not have to be in order either; you set the order in the array.

### Watch out
- If you put a `;` at the end of the `for (...)` line, the loop body stays empty; the `{ }` block after it is not part of the loop.
- The difference between `<` and `<=` means one round too many or too few.

### Summary
`for` repeats a job; an array keeps several values under one name. Indexes start from 0, and the last index of an N-element array is N − 1. Using the two together gives you short programs that are easy to change.
