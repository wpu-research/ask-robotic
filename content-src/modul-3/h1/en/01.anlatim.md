### What you should know first
Nothing. This lesson starts from zero. All you need is a computer and a browser that can open the lab.

### The tiny computers around you
A circuit "knows" how long the microwave oven should run, when the washing machine should drain the water, and which button on the remote control was pressed. At the heart of that circuit there is usually a **microcontroller**.

A microcontroller fits the three basic parts of a computer (processor, memory, input-output) into **a single chip**. It has no screen or keyboard; instead it has **legs (pins)**. You connect parts such as LEDs, buttons, sensors and motors to these pins. A computer is designed to do any job. A microcontroller is programmed for **a single job** and does that job all the time.

### The program stays on the chip
You upload the program to the board once. The program is written into the chip's **flash** memory and is not erased even if the power is cut. When you start the board again, the program starts by itself. That is why a device works straight away when you plug it in.

### The Arduino Uno: a board built around the chip
The brain of the Arduino Uno is the **ATmega328P** chip. The board comes with parts that make the chip easy to use:

- **Digital pins (0-13):** Output HIGH or LOW, or read from outside.
- **Analogue input pins (A0-A5):** Measure a voltage between 0 and 5 V.
- **5V and GND pins:** Give parts 5 volts and ground (0 V).
- **Built-in L LED:** Connected to D13. You can experiment without adding any parts.

You can find these parts on the Uno drawing in the lab. The lab does the real board's USB jobs, uploading the program and supplying power, for you.

### HIGH and LOW
A digital pin is in one of two states. **HIGH** is when the pin gives about 5 V; **LOW** is when it gives 0 V. If a pin is set as an **output**, the board drives the pin itself (for example, it lights an LED). If it is set as an **input**, the board listens to the pin (for example, it reads a button). You make this setting in the program with the `pinMode` command.

### The two parts of every program
An Arduino program is called a **sketch**. It has two parts:

```
void setup() {
  // runs ONCE when the board starts
}

void loop() {
  // runs over and over, from start to end, again and again
}
```

`setup()` is for preparation (such as setting the direction of the pins). `loop()` is the main job, and when it reaches the end it goes back to the start. As long as the board has power, this loop never stops.

### Summary
A microcontroller is a tiny computer on a single chip, and it is programmed for a single job. The Arduino Uno makes this chip usable through its pins. Pins are HIGH or LOW; the `setup()` part of the program runs once, and the `loop()` part runs all the time. Now, in the activity, you will open the lab and get to know the Uno.
