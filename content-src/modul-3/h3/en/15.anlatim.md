### What you will learn in this lesson
- Combining three sensors (LDR, potentiometer, NTC) in one program
- Writing a small version (stage) first and then extending it
- Getting "bright in the dark" behaviour by writing the `map` output range the other way round
- Putting the settings numbers at the top with `const`
- Setting the priority of several conditions (safety, then normal behaviour)

### What you should know first
From lesson 11, `analogRead` and `ham / 4`; from lesson 12, the LDR divider; from lesson 13, the NTC temperature; from lesson 14, `map`, `constrain` and averaging; from lesson 5, the project plan.

### Plan first
Before writing the code, write down what each input affects:

| Input | Pin | Effect |
|---|---|---|
| LDR | A1 | As the room gets darker, the lamp gets brighter |
| Potentiometer | A0 | The lamp's maximum brightness |
| NTC | A2 | If it goes above 40 °C, the lamp turns off and the warning LED turns on |

Outputs: lamp D11 (PWM), warning D13.

### Reverse map
In the dark `ham` is small, so the brightness should be large. For this, the `map` output range is written the other way round:

```
map(isik, KARANLIK, AYDINLIK, enYuksek, 0)
```

Example: if KARANLIK = 150, AYDINLIK = 700, enYuksek = 200 and isik = 425, you get (425−150) × (0−200) / 550 + 200 = 100. At a light of 150 it is 200, at 700 it is 0. `constrain(…, 0, enYuksek)` prevents overflow.

### Order of priority
First the normal brightness is calculated, then the safety condition overrides it: if the temperature limit is exceeded, the brightness is set to 0 and the warning is turned on. Writing the safety check at the end stops the earlier steps from spoiling it.

### Developing in stages
First only the LDR and the lamp (stage 1). When that works, the potentiometer, averaging and the NTC are added (stage 2). If you watch the `isik`, `parlaklik` and `sicaklik` values in the Serial monitor after each addition, you find straight away which addition brought in the bug.

### Summary
The project combines the three sensors of the analog week: the LDR sets the brightness, the potentiometer sets the upper limit, and the NTC provides safety. Reverse `map` gives the bright-in-the-dark behaviour. Plan first, then a small version, then additions: finding bugs becomes easier.
