### How does the game remember the key?
The cat touches the key, and a little later it comes to the door. When the door event runs, how will it know the key was taken a moment ago? The two events cannot see each other; they need to leave a note in a shared place.

This note is a **flag** variable: `anahtarVar`. It only takes two values: 0 (no) and 1 (yes). The key event sets the flag to 1, and the door event reads the flag.

```
when game starts:        anahtarVar = 0
when touching key tile:  anahtarVar = 1
when touching door tile: if anahtarVar = 1 do win, else "Locked!"
```

### A two-way decision
The `if … do` block only runs the "yes" path. When you add an `else` branch, you also say what happens for "no". At the door this is a must: if there is no key, the player should learn something; otherwise the door just stands there like a wall that does not explain why it will not open.

### Tile or pixel?
The map is made of 16-pixel tiles. The maze in this game is 20 columns by 9 rows, that is 320 × 144 pixels. The screen is only 160 × 120 pixels; that is why the camera follows the cat.

`put on tile column [1] row [1]` wants a tile number, and the numbers start from 0. The pixel position of the middle of a tile is:

```
x = column × 16 + 8
y = row × 16 + 8
```

For column 1, row 1, x = 24 and y = 24. If you type a pixel number into the tile block instead, the sprite goes far off the map.

### The chaser and speed
The ghost has the `ghost` setting (go through walls); it passes through walls. On the other hand, its speed is 14 and the cat's speed is 60 pixels/s. The ghost always gets closer to the cat, but the cat can easily get away by running. What makes things hard for the player is not the ghost's speed, but the maze walls and the chance of the cat being cornered.

If the ghost catches the cat, they both go back to their starting tiles. This way the player is not caught again straight away.

### Summary
A flag variable (0 or 1) carries information between two events. `if … do … else` gives an answer for both possibilities. Tile numbers start from 0, and multiplying by 16 and adding 8 turns them into the middle pixel. The chaser's speed decides whether the game is fair or hard.
