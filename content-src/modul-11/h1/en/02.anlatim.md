### What you will learn in this lesson
- That the keys the player uses are called the **controller**
- How to move a sprite with the arrow keys
- The idea of **speed** (how many pixels a second) and how to work it out
- The three ways of moving and when to choose each one
- How to stop a sprite from leaving the screen

### What you should know first
Lesson 1: stage, sprite, position (x and y), variable and the `when game starts` block.

### Controller: the game's remote
The player talks to the game through keys. All the keys in the Game Workshop together are called the **controller**. There are four direction keys (or W, A, S, D) and two buttons:

| Key | On the keyboard | On a touch screen |
|---|---|---|
| Direction keys | arrows or W A S D | the direction keys under the stage |
| A button | Space or Z | the A on the screen |
| B button | X or Enter | the B on the screen |

### Say it once, it works forever
You run the `kedi moves with player keys` block once, and its effect lasts forever. The game looks at the keys 60 times a second. If it sees a direction key held down, it slides the cat that way. You do not build a loop for this yourself; the game repeats it for you.

### Speed and way of moving
**Speed** tells you how many pixels the sprite goes in one second. If you write speed 60 in the block, the cat walks 60 pixels a second while the key is held down. Since distance = speed x time, it goes 120 pixels in 2 seconds. The stage is 160 pixels wide, so a cat with speed 60 crosses the screen in about 2.7 seconds.

There are three ways of moving:

| Way | Which keys work | Good for |
|---|---|---|
| in 4 directions | up, down, left, right | maze, top-down game |
| left-right | only left and right | platform game, fruit basket |
| up-down | only up and down | vertical scrolling game |

If left-right is chosen and you press the up key, nothing happens. This is not a bug; it is the rule of the way of moving you chose.

### The stay on screen setting
If you say nothing, the cat passes the edge of the screen and goes out. When it goes out, it is not deleted; it just cannot be seen; it is still in the game. The **stay on screen: yes** setting stops the cat at the edge of the stage. You put this setting inside `when game starts` too, under the movement block.

### Summary
The controller is the player's keys. The key movement block is run once and stays in force for the whole game. Speed is the number of pixels travelled in a second; distance is speed times time. The way of moving decides which keys work. The stay on screen setting keeps the sprite inside the stage.
