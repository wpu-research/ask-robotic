### What you will learn in this lesson
- That a map is a grid made of small square pictures (tiles)
- That columns and rows are counted starting from 0
- What it means for a tile to be a "wall"
- The difference between drawing the map, loading it into the game and putting a sprite on a tile

### What you should know first
The lessons in module 11, week 1 and week 2: stage, sprite, moving with the arrow keys and lining blocks up under `when game starts`. No new idea is needed.

### A map is a grid
So far you have moved sprites around an empty stage. Real games have rooms, corridors and mazes. Instead of drawing these piece by piece, we lay small square pictures called **tiles** side by side. A tile is 16 x 16 pixels. The grid the tiles are laid out in is called a **map**.

The room in this lesson has 10 columns and 7 rows:

```
width = 10 tiles x 16 pixels = 160 pixels
height = 7 tiles x 16 pixels = 112 pixels
```

The screen is 160 pixels wide, so the room fits the screen exactly.

### Column and row numbers start from zero
Two numbers are enough to describe a tile: the **column** (from left to right) and the **row** (from top to bottom). The top left corner is column 0, row 0. So the last column of a map with 10 columns is 9.

```
        column 0   1   2   3 ...
row 0       [ ] [ ] [ ] [ ]
row 1       [ ] [ ] [ ] [ ]
row 2       [ ] [ ] [ ] [ ]
```

The centre of a tile is at column x 16 + 8 and row x 16 + 8 pixels. The centre of the tile at column 5, row 3 is the point (88, 56).

### Tile set and wall
To paint the map you use a **tile set**. Every tile in the set has a **wall** box. If the box is ticked, a sprite cannot go into that tile; if it is not ticked, it walks over it.

| Tile | Wall box | What does the sprite do? |
|---|---|---|
| Stone wall | ticked | Stops |
| Water | ticked | Stops |
| Grass | not ticked | Walks over it |

Painting the tile with the right picture is not enough; you also need to set the box correctly. You do not write a separate block for the wall to work.

### Drawing a map is different from loading it
The map you draw in the Map tab does not go into the game by itself. The `load map` block must run inside the `when game starts` block. Placing the sprite with the `put sprite on tile column row` block is also easier than counting pixels. If a single gap is left in the outer wall, the sprite gets out through it; the room must be fully closed.

### Summary
A map is a grid of 16 x 16 pixel tiles, and columns and rows are counted from 0. Tiles with a ticked wall box stop the sprite. You draw the map in the Map tab, but for it to appear in the game you need to run the `load map` block.
