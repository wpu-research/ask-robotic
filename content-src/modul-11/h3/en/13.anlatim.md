### What you will learn in this lesson
- How to find out the column and row of the touched tile with the "event tile" blocks
- How to clear exactly that tile from the map
- How to count how many of a certain tile are left on the map and win with it
- How to lower the lives on a dangerous tile and send the player back to the start

### What you should know first
Lesson 11 (column, row, counting from 0) and lesson 12 (the touching a tile event and ending the game). Remember the score and lives blocks from week 2 too.

### Which tile did I touch?
There are four diamonds on the map. The same `touches tile [Diamond]` event looks after all of them. Inside the event, two blocks tell you which diamond the cat touched: `event tile [column]` and `event tile [row]`. If you give these to the `clear tile at column row` block, **the diamond you touched** disappears and the others stay where they are.

If you write fixed numbers, for example column 3 row 2, the same tile is always deleted.

### Winning by counting
When the diamonds run out, the game should be won. The `number of [Diamond] tiles on map` block tells you how many diamonds are left on the map. The rule: win when the number is 0.

```
clear the diamond tile
change score by 1
if number of diamonds on map = 0
    end game: you win
```

**Order matters.** If you do the check before clearing the tile, at the last diamond the number still shows 1 and the game is never won. Clear first, then count.

| Left | Checking before deleting, as the last diamond is taken | After deleting |
|---|---|---|
| 1 | number 1, not won | number 0, won |

### Lava: a dangerous tile
You write a second event for the lava tile: `change lives by [-1]`, shake the screen, play a boom sound and `put sprite [this sprite] on tile column [1] row [1]`. Column 1, row 1 is the first tile just inside the outer wall, and it becomes the starting point. `this sprite` is the sprite that triggered the event; so it is the cat.

If you forget the teleport, the cat stays on the lava. The event runs once, so a life is lost only once; but the player is still standing in the danger.

### Summary
The event tile's column and row tell you which tile was touched; with them, exactly that tile is cleared. You must do the winning check after the tile has been cleared. Dangerous tiles like lava lower the lives and send the player back to the start.
