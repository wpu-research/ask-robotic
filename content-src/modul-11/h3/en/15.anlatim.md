### What you will learn in this lesson
- How to split a game's rules into tile events
- How one event, like key and door, changes another place
- How to plan with a rule table first and then build the blocks
- How to make the game harder or easier by changing the map

### What you should know first
Lessons 11-14: map and walls (11), the touching a tile event (12), clearing the event tile, winning by counting and lava (13), the camera (14). This lesson brings them all together.

### Rule table first
There are four rules on treasure island. Before you build the blocks, write in a table what will happen on which tile:

| Tile | What happens when you touch it? |
|---|---|
| Key | The key disappears, the door tile (column 10, row 5) disappears |
| Diamond | The diamond disappears, the score goes up by 1 |
| Lava | The lives go down by 1, the hero goes back to the start |
| Chest | A message with the score is written, the game is won |

Each row is an event: four `touches tile` blocks in total.

### One event changes another place
In the key event, two tiles are cleared. The first is the key you touched; you do this with the event tile's column and row. The second is the door; its place is fixed, so you type the numbers yourself: column 10, row 5. The door tile has its wall box ticked, so it stops the hero. When the tile is deleted, the wall goes too and the way through opens.

Do not mix up the column and the row. The island has 20 columns and 10 rows. Column 10 row 5 and column 5 row 10 are different places. The second one is outside the map, and no tile is deleted.

### Big island, scrolling camera
The map is 20 x 10 tiles: 320 x 160 pixels. The screen is 160 x 120, so the camera follows the hero. The camera x can be at most 320 - 160 = 160, and the camera y at most 160 - 120 = 40.

### Show that you have won
The message in the chest event is made with the `create text with` block: first the text `You found the treasure! Score: `, then the `score` block. If there are three diamonds and each one is worth 1 point, the message says 3. If you make the diamond's value 2, the message says 6; the message reads the score itself.

### Summary
The game's rules are tile events. First you make a table, then you turn each row into an event block. In the key and door system, one event deletes another tile. The camera lets you see the work from the rule table.
