### What you will learn in this lesson
- The difference between speed and acceleration
- That gravity in a game is an "acceleration"
- That the y axis grows downwards
- Why you choose the "left-right" way of moving in a platform game

### What you should know first
In lesson 2 you learnt to walk the cat with the keys, and in lesson 4 the `set speed x y` block. In lesson 11 you saw the tile map and wall tiles. In this lesson you will put these together.

### Speed and acceleration are not the same thing
**Speed** is how many pixels a sprite moves each second. If the speed is 100, the sprite moves 100 pixels every second, always at the same speed.

**Acceleration** is how much the speed changes. If the acceleration is y = 400, the sprite's downward speed grows by 400 pixels/s every second. Like a bicycle going faster and faster down a hill.

```
Time     Speed (acceleration 400)
0.25 s   100 pixels/s
0.50 s   200 pixels/s
0.75 s   300 pixels/s
```

Speed = acceleration x time. As it speeds up, the sprite moves further every frame; that is why the fall looks "real".

### The y axis grows downwards
On the game screen, the top-left corner is the point (0, 0). x grows to the right and **y grows downwards**. That is why a downward acceleration is a **positive** y value. If you want to move the sprite up, you use a minus number. You will need this rule in the jumping lesson too.

### Setting up gravity
Gravity means giving the sprite a constant downward acceleration. One block is enough:

```
when game starts:
  set kahraman acceleration x 0 y 520
```

The hero falls and stops when it hits a ground tile (a wall). The engine sets the speed of a sprite that hits a wall to zero in that direction. While the hero is standing on the ground, the acceleration is still there; the wall holds it up.

### Choose the right way of moving
If you choose **in 4 directions** in the `moves with player keys` block, the engine writes the y speed again from the keys every frame. If you are not pressing a key, the y speed becomes 0 and gravity has almost no effect; the hero drifts down very slowly. If you choose **left-right**, only the sideways speed depends on the keys, and the up-down speed is left to gravity.

### Summary
Speed tells you how fast a sprite is going; acceleration tells you how quickly that speed changes. Gravity is a positive acceleration in the y direction, because y grows downwards. In a platform game you choose left-right as the way of moving so that gravity can work. Because the ground tiles are walls, the hero stops when it lands.
