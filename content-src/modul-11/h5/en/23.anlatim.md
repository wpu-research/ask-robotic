### What you will learn in this lesson
- That tiles such as gold and spikes are not walls, but can trigger events
- That the `touches tile` event is edge-triggered
- How to find where the touched tile is with `event tile column / row`
- How to turn a column and row number into a pixel position

### What you should know first
In lessons 11-13 you learnt about the map and the `touches tile` event. In lesson 9 you used the `change lives` and `shake screen` blocks. The gravity and jumping from lessons 21-22 give this scene its movement.

### Every tile is something
The map is made of tiles, and each tile is 16 x 16 pixels. There are two kinds of tile:
- **Wall tile:** a sprite cannot pass through it (ground, platform).
- **Passable tile:** a sprite passes through it (gold, spikes, door). But the engine triggers an event saying "this sprite touched that tile".

If you made the gold and spikes walls, the hero could never get into them; it would just stand on top of them. To collect or get hurt, it must be able to go inside them.

### Edge triggering
The `when a Player sprite touches tile [Gold]` block runs **once**, at the moment the hero enters the tile. It does not run again for as long as you stay on the same tile. If you leave the tile and enter it again, it runs again.

That is why you must **clear** the tile when you collect the gold. If you do not clear it, the gold stays visible and gives points every time the hero leaves and comes back in.

### Which tile?
There can be lots of gold on the map. The same event runs for all of it, so you need to know which one to clear. The answer is the event blocks:

```
clear tile at column (event tile column) row (event tile row)
```

If you type a fixed number, the same tile is always cleared.

### From tile number to pixels
Columns and rows start from 0. When you put a sprite on a tile, the sprite's **centre** goes to the middle of the tile:

```
centre x = column x 16 + 8
centre y = row x 16 + 8
Column 2, row 5  ->  x = 40, y = 88
```

### Reset after the spikes
In the spikes event, when you put the hero on the starting tile, set its speed to zero too. If you were going up when you jumped into the spikes and you do not reset the speed, the hero shoots up into the air from the starting tile.

### Summary
Tiles such as gold, spikes and doors are not walls; the hero passes through them and the engine triggers a touch event. The event runs once when the tile is entered. The `event tile` blocks tell you which tile triggered it. You find the centre pixel of a tile by multiplying the tile number by 16 and adding 8.
