### What you will learn in this lesson
- How to plan a game as a list of rules
- How to combine the week's pieces (gravity, jumping, tile events, stomping) in one level
- How to work out the map size and why a camera is needed
- How to play the game and adjust the difficulty

### What you should know first
This project uses all of lessons 21-24: gravity (21), jumping (22), gold and spikes (23), stomping the enemy (24). For the door, remember the `show on screen` and `end game` blocks from lesson 13. For the camera, look at lesson 14.

### A rules table first
Break a big job into pieces. Each rule answers these three questions: **Touching what? What happens? Which block?**

```
Rule    Trigger                     Result
Gold    Player + Gold tile          tile cleared, score +1
Spikes  Player + Spikes tile        lives -1, back to start, speed 0
Door    Player + Door tile          message, win the game
Stomp   Player + Enemy collision    enemy gone, score +5
```

The rules table is a checklist: while you play, try each row one by one.

### Map size
Each tile is 16 pixels, and the screen is 160 x 120 pixels.

```
Map 24 x 8 tiles  ->  384 x 128 pixels
Screen 160 pixels wide  ->  384 - 160 = 224 pixels outside
```

The camera follows the hero for the 224 pixels that do not fit on the screen. Without the camera you would never see the door on the right.

### The pieces work together
The gold, spike and door events are separate, but they run in the same scene. The score comes from both the gold and the stomping. When you add a new rule, try again to make sure the earlier rules have not broken.

### Put yourself in the player's shoes
When the game is finished, play it: are the first spikes too close? Is it too hard to reach the gold? A good level goes from easy to hard. The first obstacle is easy, and the later ones slowly get harder. If you change the winning condition (for example, score ≥ 10 for the door), check whether the points let players meet this condition some other way. Because the score comes from both gold and stomping, players can get through in whichever way they like.

### Summary
You plan a game with a rules table: trigger, result and block. In this project, gravity, jumping, tile events and stomping enemies come together in one level. Because the map is 384 pixels wide, a camera is needed. When it is finished, you play the game and check the difficulty and that the rules do not break each other.
