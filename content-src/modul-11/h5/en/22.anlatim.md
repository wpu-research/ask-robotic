### What you will learn in this lesson
- That a jump is a minus value given to the y speed
- How gravity slows a jump down and turns it round
- How to ask "am I on the ground?" with an `if` block
- How to set the jump strength with the speed value

### What you should know first
The acceleration and gravity from lesson 21 are the base of this lesson; remember that the y axis grows downwards. In lesson 3 you saw the button event (`when A button is pressed`), and in lesson 7 the `if` block.

### Jumping = a sudden upward speed
To jump, you give the hero an upward speed all at once. Because y grows downwards, an upward speed is a **minus** number.

```
when A button is pressed:
  set kahraman speed x (kahraman x speed) y -250
```

You gave the speed once; gravity does the rest. Every second, 520 is added to the speed, so the minus speed gets smaller, reaches zero (the highest point) and becomes positive (falling). The hero comes down by itself.

### Height and time
The rise is about speed x speed / (2 x acceleration). The time is speed / acceleration.

```
Speed -250, acceleration 520:
  rise = 250 x 250 / (2 x 520) = about 60 pixels
  time to the top = 250 / 520 = about 0.5 seconds
```

If you double the speed, the rise becomes four times bigger, because the speed appears twice in the multiplication. That is why you should adjust the jump strength in small steps.

### Stop jumping in mid-air
If you do not add a guard, every press of A gives a new speed and the hero jumps in the air too; it is almost like flying. The fix is to ask a condition:

```
when A button is pressed:
  if is kahraman touching a wall below? do:
    jump
```

`touching a wall below?` is only true if there is a wall right under the hero: the ground or a platform. In the air it is false, and the block does not run.

### Keep the sideways speed
If you type 0 in the `x speed` slot when jumping, the hero goes straight up and straight down. If you put the hero's own `x speed` in the slot, it keeps going in the direction it was walking while it jumps.

### Summary
A jump is giving the hero's y speed a minus value. Gravity takes this speed away and brings the hero back down. To stop jumps in mid-air, you link the jump to the condition `touching a wall below?`. The jump height grows with the square of the speed, so choose the value by trying it in small steps.
