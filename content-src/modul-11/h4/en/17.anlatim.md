### What you will learn in this lesson
- How to send one sprite after another sprite
- What the distance between two sprites means and how it is measured
- How to build the rule "chase if near, stop if far" with `if ... else`
- The difference between `stops` and `stops following`

### What you should know first
Lesson 16: speed and distance (distance = speed x time). From earlier weeks: the `if` block, choosing a sprite with a variable, the `every frame` event and walking a sprite with the arrow keys.

### How does following work?
The `hayalet follows kedi at speed 25` block makes the ghost look towards the cat every frame and move that way at 25 pixels/second. If the cat moves, the ghost corrects its direction by itself. The follow speed is fixed: if the cat is running at speed 60, the ghost at speed 25 can never catch it. When the ghost comes closer than 1 pixel to the cat, it stops; it does not climb on top of it.

An important detail: if you put the same sprite in both slots (the ghost follows the ghost), the block does nothing.

### Distance
The `distance from hayalet to kedi` block gives the distance between the **centres** of two sprites, in pixels. It combines the sideways difference and the up-down difference with Pythagoras' theorem:

```
dx = 80 - 20 = 60
dy = 110 - 30 = 80
distance = square root(60 x 60 + 80 x 80) = 100
```

The distance is always zero or positive; it does not matter which sprite you write first.

### The detection threshold
If the ghost chases across the whole map, the game becomes hard. Instead we choose a **threshold**: if the distance is smaller than the threshold, the ghost "wakes up". The rule:

```
every frame:
  if distance < 70 do
    hayalet follows kedi at speed 25
  else
    hayalet stops
```

The `every frame` event runs 60 times a second, so the ghost checks "is the cat near?" 60 times a second. If you put this check inside `when game starts`, it is only checked once; even if the cat comes close later, the rule is not tested again.

### stops and stops following
`stops` sets the speed to zero and ends the following. `stops following` only ends the following; the speed stays as it is. The ghost keeps sliding in its current direction at its current speed. That is why we put `stops` in the "else" branch.

### Summary
The follow block walks one sprite towards another at a fixed speed. The distance block measures between the centres in pixels. By combining a distance threshold with `if ... else`, you make the ghost an enemy that only wakes up when you are near. To really stop following, use `stops`.
