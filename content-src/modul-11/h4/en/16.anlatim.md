### What you will learn in this lesson
- How to make an enemy go back and forth on its own
- When, and how many times, the timer event (`every ... ms`) runs
- The link between speed, time and distance (distance = speed x time)
- How the `reverse speed` block changes the sign of the speed

### What you should know first
From earlier weeks: making a sprite and giving it a kind (weeks 1 and 2), giving a sprite a speed (lesson 4), choosing a sprite with a variable. You do not need anything else.

### What is a patrol?
A guard walks along the same corridor every night: forward, back, forward, back. In games this is called a **patrol**. An enemy on patrol does not see the player; it only follows its own pattern. The player learns this pattern and tries to get past at just the right moment. It is a simple idea, but it makes the game "come alive" for the first time.

### Speed and distance
In the engine, speed is measured in pixels per second. If the bat's sideways speed is 40, it moves 40 pixels to the right every second. The link between them:

```
distance = speed x time
40 pixels/s x 1.5 s = 60 pixels
```

The sign of the speed gives the direction: a positive x speed goes right, a negative x speed goes left. For up-down speed, a minus value means up, because y is zero at the top edge of the screen.

### The timer event
The `every 1500 ms` block is an **event**. While the game is running, it runs the blocks inside it once every 1500 milliseconds (1.5 seconds) and keeps repeating this without stopping. A millisecond is one thousandth of a second: 1000 ms = 1 second. The timer can be 50 ms at the least; if you write a smaller number, the engine makes it 50.

### Reversing the speed
For a patrol you do not need to write two separate movements. The `reverse speed` block changes the sign of the speed: a speed of 40 becomes -40, and -40 becomes 40 again. Watch which direction is selected in the block: if x (sideways) is selected, the sideways speed is reversed; if y (up-down) is selected, the up-down speed is reversed. If you write "set speed x 40" in the timer, the speed becomes 40 again every time and the bat never turns; giving a new value and reversing the one you have are different things.

At the start the bat goes right, after 1.5 seconds it turns left, and after 3 seconds it goes right again. Because the times going and coming back are equal, the bat returns to its starting point every 3 seconds.

### Summary
A patrol is an enemy going back and forth regularly. Speed is pixels per second, and distance is speed times time. The `every ... ms` event runs at a set interval; the `reverse` block you put inside it changes the sign of the speed and turns the bat round. Remember to choose the right direction (x or y).
