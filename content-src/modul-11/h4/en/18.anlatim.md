### What you will learn in this lesson
- How direction is given in degrees (0 up, 90 right, 180 down, 270 left)
- The `moves in direction ... degrees at speed` block
- How to choose the right range for the random number block
- How a computer makes a "random" number

### What you should know first
Lesson 16: the `every ... ms` event and speed. From earlier weeks: making a sprite, the `stay on screen` setting and the speed block.

### Direction, in degrees
Instead of telling a sprite "your x speed is this, your y speed is that", you can say "go this way at this speed". Direction is in degrees and is read like a compass:

```
  0 degrees   = up
 90 degrees   = right
180 degrees   = down
270 degrees   = left
```

The numbers in between are diagonals: 45 is up-right, 225 is down-left. The `moves in direction ... degrees at speed` block turns these two pieces of information into x and y speeds for you. For example, if the direction is 270 and the speed is 30, the x speed becomes -30 and the y speed 0. The sprite travels 90 pixels to the left in 3 seconds.

### Random numbers
Each time it runs, the `random integer from [1] to [100]` block picks a whole number from the given range. Both end numbers can be picked: if you say 5 to 8, you get 5, 6, 7 or 8 (4 possibilities). For direction you need the range 0 to 359, which covers the whole circle. If you write 1 to 100, all the directions are on the right-hand side and the bat never goes left.

### Why random?
If an enemy always takes the same path, the player learns it by heart. Random movement makes the enemy unpredictable. The timer length sets its character: 300 ms makes the bat jumpy and hard to avoid, while 2000 ms makes it one that goes the same way for a long time and is easy to predict.

### The seed: computers do not roll dice
A computer does not really roll dice. It makes random numbers with a formula. The formula starts from a starting number, called the **seed**. If you start with the same seed, you always get the same list of numbers. In this game the seed changes on every run, so the bat draws a different path each time. The activity's own check tries two different seeds and makes sure the paths are different.

### Summary
Direction is between 0 and 359 degrees: 0 up, 90 right, 180 down, 270 left. `moves in direction ... degrees at speed` gives the direction and the speed together. The random number range must be chosen to cover every direction (0-359). Randomness is a formula with a seed; the timer length decides how restless the enemy will be.
