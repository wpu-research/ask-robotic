### The there-and-back time of light
**ToF** (Time of Flight) means the sensor sends out a short pulse of light and measures how long the reflection takes to come back. The distance is worked out from the speed of light and this time. The VL53L0X does this with an infrared laser and gives the result in **millimetres**. Since 1 cm = 10 mm, 300 mm means 30 cm.

There is an important note here: there is no VL53L0X part in the lab. In this lesson you write and compile the code; you cannot see the measured values virtually. If you run it without a sensor, the program prints "VL53L0X bulunamadi" (VL53L0X not found), and this is proof that the error check works.

### I2C and the address
The sensor is connected to the Arduino with two wires: SDA (A4) and SCL (A5). There can be other I2C devices on the same bus; each one has a different address.

| Device | Address |
|---|---|
| I2C LCD (in this course) | 0x27 |
| VL53L0X | 0x29 |
| MPU6050, RTC | 0x68 |
| BMP280 | 0x76 |

To be sure of the connection, you run the address scanner program from lesson 33 and look for 0x29 in the output. Bare chips work on 3.3 V; ready-made boards usually have a regulator, but you check the board's documentation before connecting power.

### Defending against errors
Library calls need two checks:

```
if (!sensor.init()) { ...sensor not found... }
int mm = sensor.readRangeContinuousMillimeters();
if (sensor.timeoutOccurred()) { ...reading invalid... }
```

`init()` returns `false` if it cannot reach the sensor. `timeoutOccurred()`, on the other hand, becomes `true` if the reading did not finish in time. You must also call `Wire.begin()`; if the I2C bus is not started, you cannot talk to the sensor. Taking the number returned by a failed reading for a real distance is the most common mistake.

### Threshold and hysteresis
As in the HC-SR04 lesson, two values are used for the distance threshold. Example: below 300 mm is "close", above 340 mm is "far". The gap between them is 40 mm, that is, 4 cm.

```
readings: 350, 295, 305, 296, 310, 345, 330, 290 (mm)
single threshold (300): close-far-close-far ... the state changes 5 times
two thresholds (300/340): only "close" at 295, "far" at 345, "close" at 290: 3 changes
```

### ToF and ultrasonic
ToF uses light, the HC-SR04 uses sound. The HC-SR04 needs two digital pins and `pulseIn`; the VL53L0X uses two I2C pins and shares them with other I2C devices. Both are sensitive to the surface: sound can scatter on soft surfaces, and light can be affected by dark and shiny surfaces or by strong ambient light. For the exact range and accuracy, check the datasheet.

### Summary
The VL53L0X measures distance in millimetres from the time of flight of light and talks over I2C at address 0x29. In the code, errors must be caught with `Wire.begin()`, `init()` and `timeoutOccurred()`. In threshold decisions, keeping the close and far values apart stops the state from flickering.
