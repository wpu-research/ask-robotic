### Safety first
Gas leaks and flammable gases are dangerous. There is no real gas in this lesson: you imitate gas with the **Gas level** value on the virtual module. This circuit does **not** replace a certified gas or smoke detector; it is for learning only.

### What does the MQ-2 do?
Inside the MQ-2 module there is a heated sensing element. Flammable gases and smoke change this element's resistance; the module gives this out as a voltage on the analog output (AO). As the gas rises, AO rises. On the virtual module AO = 5 V × (0.1 + 0.9 × level):

```
Gas level:    0     0.03   0.1   0.3    1
analogRead:  102    130    194   379   1023
```

The MQ-2 **cannot tell** which gas it is. It only says "it has risen compared with clean air".

### Warm-up
Until the heater brings the element up to its working temperature, the readings are unsteady. On a real module this takes a long time and is given in the datasheet. In the lesson we use 5 seconds so we do not have to wait. The virtual module does not model the warm-up, but we still wait in the code because the real module behaves that way.

### Baseline and relative threshold
After the warm-up, you take the average of a few readings in **clean air**: this is `baz`. The baseline is different for every module and every place. So instead of writing the threshold as a fixed number (`okuma > 400`), you write it as a multiple of the baseline:

```
float oran = ort / baz;     // 1.0 = clean air
```

Careful: if `ort` and `baz` are both `int`, `ort / baz` does integer division. 160 / 100 gives 1, not 1.6. That is why `baz` or `ort` is kept as a `float`.

### Why don't we write ppm?
To convert to ppm, you need the curve from the datasheet, the type of gas and a calibration. Without these, the number you get looks reliable but is not. We only look at "how many times the clean-air value" it is.

### A steady alarm
The alarm must not depend on a single spike:
1. Smooth the reading: `ort = 0.8 * ort + 0.2 * okuma`.
2. Use two thresholds: start when the ratio rises to 1.5, end when it drops below 1.2.

### Summary
After the MQ-2 has warmed up, a baseline is measured in clean air. The alarm threshold is not a fixed number but a multiple of the baseline. ppm is not written because there is no calibration. Smoothing and two thresholds make the alarm steady. This circuit is for learning and is not used to protect real lives.
