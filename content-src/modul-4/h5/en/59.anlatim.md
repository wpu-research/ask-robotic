### Add up the rate, find the angle
A gyroscope does not give the angle; it gives the **rate of turn** (°/s). For the angle, the rate is multiplied by the elapsed time and added up:

```
aci = aci + hiz * dt;     // hiz (rate): degrees/s, dt: seconds
```

Example: a chip turning at 10 °/s for 3 seconds turns 30 degrees. The units must match: if `dt` is in milliseconds, the result is 1000 times too big.

### Bias builds up
A still gyroscope does not show exactly zero; it reads a constant **bias** of a few °/s. You find the bias with the average of hundreds of readings while the chip is not moving, and you subtract it from every reading. If you do not subtract the bias, the error grows straight away; even if you do, the small leftover error (the bias can drift with heat) grows as it is added up. For an unsubtracted 2 °/s:

```
bias 2 °/s   1 s -> 2 degrees   10 s -> 20 degrees   1 min -> 120 degrees
```

The calculated angle wanders away even though the chip never moved.

### Two flawed sensors
| Sensor | In the short run | In the long run |
|---|---|---|
| Accelerometer | noisy (vibration spoils it) | right, does not drift |
| Gyroscope | right, fast | drifts |

Each one covers what the other is missing.

### The complementary filter
```
aci = aci + hiz * dt;     // hiz: derece/sn, dt: saniye
```

At every step the angle is updated with the gyroscope (fast, calm), then a small pull towards the accelerometer's angle is applied (this stops the drift). `ALFA` = 0.98 means 98% gyroscope, 2% accelerometer. A worked example: if `aci` = 10, `gy` = 20, `dt` = 0.01 and the accelerometer angle is 12, the new angle is 0.98 × 10.2 + 0.02 × 12 = 10.236.

If `ALFA` gets smaller, the accelerometer gains weight: the filter does not drift, but it is affected by vibration. If `ALFA` gets close to 1, the filter is calm, but the drift comes back and it is slow to settle on the right angle. With a leftover gyroscope error `b`, the filter's lasting error is about `ALFA · b · dt / (1 − ALFA)`: for 2 °/s, 0.01 s and 0.98, about 1 degree. With the integral alone, the same error would be 20 degrees in 10 seconds.

### Summary
A gyroscope gives the rate; the angle is found by adding up the rate, and the bias builds up and causes drift. An accelerometer does not drift but is sensitive to vibration. The complementary filter adds the two together with weights: it trusts the gyroscope in the short run and the accelerometer in the long run. `dt` is calculated on every pass from the real elapsed time.
