### The weight of the air
There are kilometres of air above us, and the weight of this air creates **air pressure**. As you go higher, there is less air above you and the pressure drops. That is why a pressure sensor is also a height meter. Standard pressure at sea level is about 1013.25 hPa.

### Units
The library gives the pressure in **pascals (Pa)**. Weather reports use **hPa**, and 1 hPa = 100 Pa. For example, 101 325 Pa is 1013.25 hPa. In the code, `readPressure() / 100.0` does this conversion. Mixing up the units is the most common mistake in this lesson.

### Finding the BMP280
The BMP280 sits at address **0x76** or **0x77** on I2C. The library's default address is 0x77. If the sensor is at 0x76, `bmp.begin()` cannot find it; you need to write `bmp.begin(0x76)`. `begin` returns `true` if it succeeds and `false` if there is no sensor. If you keep this result in a variable, the program never tries to read when there is no sensor; you just print an error message.

```
bool hazir = bmp.begin(0x76);
if (!hazir) { Serial.println("BMP280 bulunamadi"); }
```

### Altitude from pressure
A common approximate formula is:

```
altitude = 44330 × (1 − (P / P0) ^ (1 / 5.255))
```

`P` is the pressure you measure and `P0` is the **current** pressure at sea level; both must be in the same unit. `readAltitude(P0)` in the library does the same calculation and expects P0 in **hPa**.

| Measured pressure | Altitude with P0 = 1013.25 hPa |
|---|---|
| 1013.25 hPa | 0 m |
| 954.5 hPa | about 500 m |
| 898.75 hPa | about 1000 m |

### When the weather changes, the altitude drifts
Sea-level pressure changes with the weather. If you give the wrong P0, the altitude drifts: near sea level, 1 hPa is about 8 m. The sensor cannot tell "the height changed" from "the weather changed". If you know your real altitude, you can turn the formula around and find P0 yourself.

### Summary
Air pressure drops as you go higher, so the BMP280 is used to work out altitude. The library gives Pa; divide by 100 for hPa. The sensor's I2C address must match the code, and the result of `begin` is checked. The altitude formula depends on P0; when the weather changes, P0 changes and the altitude drifts.
