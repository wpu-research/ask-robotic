### A small screen, a lot of data
A 16x2 LCD has 2 rows with 16 characters per row; that is 32 characters. Temperature, humidity, pressure, altitude and soil moisture do not fit at once. The fix is the phone idea: you split the information into **pages**, and the screen shows them one at a time.

### The page number and the mod operator
A variable holds which page you are on. When the time is up or the button is pressed, the variable goes up by one, and when it reaches the end it goes back to the start. `%` (the remainder of a division) does this:

```
sayfa = (sayfa + 1) % 3;    // 0, 1, 2, 0, 1, 2 ...
```

When the page is 2, 3 % 3 = 0, so you go back to the start. If you change the number of pages, only the `3` changes.

### Flicker-free updating
If you call `lcd.clear()` on every update, the screen goes blank for a moment and flickers. A better way is to **always pad the line to 16 characters**. If the new text is short, the spaces at its end cover the old characters. A format specifier does this: `%-16s` means "left-align the text and write it 16 characters wide".

### Formatting text
`snprintf(tampon, boyut, biçim, ...)` puts formatted text into a character array and does not let it go past the size. `%d` is a whole number, `%s` is text, and `%%` is a per cent sign. On the Uno, `%f` does **not** print a decimal number; you get `?` instead. For a decimal number, `dtostrf(23.4, 1, 1, tampon)` first turns the number into text, and then you place it with `%s`.

| Command | Result |
|---|---|
| `snprintf(t, 17, "Nem: %d %%", 55)` | `Nem: 55 %` |
| `snprintf(t, 17, "Sic: %f C", 23.4)` | `Sic: ? C` (on the Uno) |
| Turn it into text with `dtostrf`, then `%s` | `Sic: 23.4 C` |

### Running three jobs together
The program checks the button, reads the sensors every 2 seconds and turns the page every 3 seconds, all at the same time. None of them uses `delay`; each job has its own `millis()` timer. When you press the button, the page changes straight away and the 3-second timer starts again. If a measurement is invalid, showing `--` instead of `nan` on the screen protects the user.

### Another screen: the OLED
An OLED is a screen where every pixel makes its own light. You draw pixels instead of characters; you can choose the text size and draw lines and shapes. The image buffer of a 128x64 OLED is 1024 bytes. That is half of the Uno's 2048 bytes of memory. There is no OLED in this lab; you learn about it only by reading.

### Summary
You fit a lot of data onto a small screen with pages. The page number goes back to the start with `%`. Padding the line to 16 characters updates the screen without flicker. `snprintf` formats text, and you turn decimal numbers into text with `dtostrf`. The page change, the button and the measurement work together with `millis()`.
