### What is CSV?
**CSV** (comma-separated values) is a plain text file. Each row is a record, the columns are separated by commas, and the first row holds the column names:

```
zaman,sicaklik_C,nem_yuzde
2026-03-14 08:30:00,23.5,55.0
```

Any spreadsheet program can open this file; you draw the graph from there.

### The timestamp
The first column of each row is the **timestamp** of when the measurement was made. The format `2026-03-14 08:30:00` follows ISO 8601. It has two advantages. First, it reads the same in every country (one person reads 03.04.2026 as 3 April, another as 4 March). Second, **alphabetical order is time order**: the year comes first, then the month, then the day. For this to work, the month, day, hour, minute and second must always be written with two digits (`03`, `08`). A `millis()` value does not do the job: it resets when the board restarts, and a year later nobody can tell when "123456 ms" was.

### A separate function that builds the row
Put the row formatting in a function:

```
String satirOlustur(DateTime t, float sicak, float nem)
```

The function does not touch the hardware: it takes a time and two numbers and gives a piece of text. It can be tried with fixed values. You use the same function for both Serial and SD; the place it is written to changes, the format does not. When the sensor cannot be read, `NAN` comes in. Then you leave the field empty (`2026-03-14 08:30:00,,`); the number of columns does not change.

To turn a float into text on AVR, `dtostrf` is used, because `sprintf` does not support `%f` by default.

### The decimal separator trap
If you write the decimal with a comma (`23,5`) and the separator is also a comma, the row becomes `...,23,5,55,0` and the spreadsheet program sees 5 columns. There are two fixes: a decimal point with a comma separator (`23.5,55.0`), or a decimal comma with a semicolon separator (`23,5;55,0`). On a computer set to Turkish, the second is usually expected; this depends on the Excel version, so try it on your own computer.

### Summary
CSV is a simple text table in which each row is a record. If the timestamp is written in ISO form and with two digits, it reads the same everywhere and sorts correctly. Separating row building from the hardware makes the code easy to try. The decimal separator and the column separator must not get mixed up.
