### Why an SD card?
Say you have a temperature logger that will run in the garden for three days. EEPROM is only 1 KB; it fills up after a few hundred measurements. An SD card gives you gigabytes of space, and you can take the card out and open it directly on a computer.

### SPI: four lines
The SD card talks over **SPI**:
- **SCK:** clock pulses. Made by the Arduino.
- **MOSI:** data going from the Arduino to the card.
- **MISO:** data coming from the card to the Arduino.
- **CS:** the "select" line. The device whose CS is LOW listens.

On the Uno the SPI pins are fixed: SCK D13, MISO D12, MOSI D11. In this lesson we use D10 for CS. Do not connect LEDs to these pins and use SD at the same time. SD cards work with 3.3 V logic; a bare card slot is never connected directly to the Arduino's 5 V, so you check the ready-made module's documentation.

### The file system and the 8.3 name
The library needs a card formatted as FAT16 or FAT32. File names must be in **8.3** form: at most 8 characters, a dot, and an extension of at most 3 characters. `VERI.CSV` is valid; `sicaklik_kaydi.csv` is too long.

### The writing pattern

```
File dosya = SD.open("VERI.CSV", FILE_WRITE);
if (dosya) {
  dosya.println("23.5");
  dosya.close();
}
```

`FILE_WRITE` opens the file **adding to the end**; the old contents are not deleted. If the file does not exist, it is created. If `SD.begin(10)` fails, it returns `false` (no card, wrong wiring, or a different CS). The `if (dosya)` check tells you whether the file really opened.

### Where does the data go? close and flush
When you say `println`, the data may not go to the card straight away; it first waits in a small buffer. The physical write to the card happens with `close()` or `flush()`. So there are two safe ways:
1. **Open-write-close:** for every write, open the file, write and close. If the power is cut, the last state is safe.
2. **Keep open and flush:** open the file once and call `flush()` after every write.

On a real device, the file must be closed (or last flushed) before you remove the card or cut the power. Otherwise the last lines can be lost.

### Summary
An SD card gives large, lasting storage and talks over SPI. On the Uno the SPI pins are fixed (D11, D12, D13), and we use D10 for CS. The file name must be 8.3; `FILE_WRITE` adds to the end. The data is written to the card with `close()` or `flush()`.
