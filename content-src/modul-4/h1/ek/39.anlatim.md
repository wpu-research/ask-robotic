### Bu derste öğreneceklerin
- Tek yöne bakan sensörü servoyla tarama yapan bir sonara dönüştürmeyi
- Açıyı değiştir, bekle, ölç, kaydet döngüsünü kurmayı
- En küçük değeri (en yakın nesneyi) doğru başlangıç değeriyle bulmayı
- Sensörün ışın konisinin tarama çözünürlüğünü nasıl sınırladığını

### Önceden bilmen gerekenler
Ders 21'de servo (`attach`, `write`, darbe genişliği); ders 37'de `pulseIn` ölçümü; ders 38'de medyan filtre; ders 4'te `for` döngüsü; ders 19'da fonksiyon.

### Fikir: sensörü döndürmek
HC-SR04 yalnız baktığı yönü ölçer. Sensörü servonun koluna sabitlersen servo açısı değiştikçe sensör başka yöne bakar. Açı açı ölçüm alırsan odanın bir kesitini çıkarırsın. Denizaltıdaki sonarın mantığı budur.

### Tarama döngüsü
Her açı için aynı dört adım tekrarlanır:

```
for (int aci = 0; aci <= 180; aci += 30) {
  servo.write(aci);        // 1. açıya git
  delay(300);              // 2. servo varsın
  float cm = olc();        // 3. ölç
  // 4. aci:cm olarak yaz, en küçüğü güncelle
}
```

Bekleme adımı şart: servo daha dönerken ölçersen ölçümün hangi açıya ait olduğu karışır. 30° adımla 0, 30, ... 180 olmak üzere 7 ölçüm noktası vardır.

### En küçük değeri bulmak
En yakın nesneyi bulmak için "şimdiye kadarki en küçük"ü tutarsın. Başlangıç değeri **büyük** olmalıdır:

```
float enYakin = 400.0;     // menzilin en büyüğü
int enYakinAci = -1;       // -1: henüz bulunmadı
if (cm < enYakin) { enYakin = cm; enYakinAci = aci; }
```

Başlangıcı 0 yapsan hiçbir ölçüm 0'dan küçük olamaz ve nesneyi hiç bulamazsın. Tarama bittiğinde `enYakinAci` hâlâ -1 ise nesne yok demektir.

### Veriyi düzenli yazmak
Her ölçümü `aci:mesafe` biçiminde (örneğin `120:35.0`) yazmak iyi bir alışkanlıktır. Bir tablo programı ya da PC kodu `:` işaretinden bölerek veriyi okuyabilir.

### Işın koni gibidir
HC-SR04 tek çizgiye değil bir koniye bakar; veri sayfasında ölçüm açısı tipik olarak yaklaşık 15° verilir. 30°'lik adımlar bazı yönlerde koninin kapsamadığı boşluklar bırakabilir, ince bir nesne iki adım arasına düşüp kaçabilir. Adımı küçültürsen çözünürlük artar ama tarama uzar: her adım yaklaşık 400 ms sürüyorsa 7 adım yaklaşık 2,8 s, 19 adım (10°) yaklaşık 7,6 s eder.

### Özet
Servo ve ultrasonik sensör birlikte tarama yapar: açıyı ayarla, servoyu bekle, ölç, kaydet. En yakın nesne, büyük bir değerle başlayan "en küçüğü tut" mantığıyla bulunur. Adım küçüldükçe çözünürlük artar ama tarama süresi uzar; ışın konisi nedeniyle çok küçük nesneler kaçabilir.
