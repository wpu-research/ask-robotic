### The cost of a sudden movement
When you say `servo.write(30)`, the servo rushes from its current 90° position to the target as fast as it can. The arm jolts, the object at its tip swings or falls, and a sudden load hits the gears. That is why arms in factories move smoothly. The solution is to move forwards in small steps instead of going to the target in one move.

### Linear interpolation
Choose the movement time `sure` (ms). Measure the time since the start as `geçen` (elapsed). How much of the movement is finished:

```
ratio = elapsed / time          (between 0 and 1)
angle = start + (target − start) · ratio
```

Example: the shoulder is to go from 30° to 90° in 2000 ms. After 500 ms, `oran = 0,25` (ratio) and the angle is `30 + 60 · 0,25 = 45°`. If you drive the three servos with the same `oran`, all three arrive at the same moment.

There are two traps:
1. `oran` must not go past 1, otherwise the servo overshoots the target: `if (oran > 1) oran = 1;`
2. If `geçen` and `sure` are integers, the division is integer division: the result comes out as 0 or 1 and the movement is sudden again. Convert one of them to `float`.

### Servo frames
A servo gets a new pulse every 20 ms. So updating the angle every 20 ms is enough. A 900 ms step is 900 / 20 = 45 frames. If you are going to move 60° in one step, each frame gets 60 / 45 ≈ 1.3°; for a servo this counts as a smooth movement.

### Non-blocking movement
A smooth movement made with `for` and `delay()` does not let any other job run while the movement lasts (lesson 26). With `millis()`, `loop()` always stays free and can read sensors later.

### Step table
The pick-and-place job is a table: each row is a step (target x, y; gripper state; time). The code only runs through the table in order. For a new job you change the table, not the code. The order matters:

| Step | What happens | Rule |
|---|---|---|
| Go above the object, lower down | The arm moves | Gripper open |
| Grab | Arm still, gripper closes | The gripper closes only while the arm has stopped |
| Lift, carry, lower | The arm moves | Gripper stays closed |
| Release | Arm still, gripper opens | The gripper opens only while the arm has stopped |
| Rise, go home | The arm moves | Gripper open |

If you close and open the gripper while the arm is moving, the object falls. If you force the gripper up to its mechanical limit, the servo heats up and the gears get damaged.

### Summary
A smooth movement means producing in-between angles between the start and the target in proportion to time. `oran` rises from 0 to 1; it is limited at 1, and you watch out for integer division. Done with `millis()`, the program also stays free for other jobs. Writing jobs such as pick-and-place as a step table keeps the code simple and easy to change.
