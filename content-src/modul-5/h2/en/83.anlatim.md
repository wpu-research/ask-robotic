### The servo gives the sensor a direction
The HC-SR04 looks in one direction. If you put it on top of a servo, the servo angle becomes the direction it looks in:

| Servo angle | Beam direction |
|---|---|
| 30° | 60° to the robot's right |
| 60° | 30° to the right |
| 90° | straight ahead |
| 120° | 30° to the left |
| 150° | 60° to the robot's left |

To remember it: 90° is ahead, a large angle is left.

### Finding the farthest direction
You keep the angles in an array: `{30, 60, 90, 120, 150}`. You go to each angle, measure the distance and remember the largest so far:

```
if (cm > enIyiCm) {
  enIyiCm = cm;
  enIyiAci = ACILAR[i];
}
```

Because the comparison is `>`, if two directions come out equally far, the first one found stays. Example measurements: 30° → 40, 60° → 80, 90° → 60, 120° → 80, 150° → 20 cm. The largest is 80, and it appears twice; the code chooses the first one, that is, 60°.

### Give the servo time
The `write(angle)` command does not take the servo to its target instantly; the servo turns for a while. If you measure during this time, you measure a mix of two directions. In the lesson, it waits 300 ms at each angle. For five angles, this waiting alone comes to 5 × 300 = 1500 ms. Together with the measurements, the scan takes about 1.7 seconds and the robot stands still during this time. More angles means a better direction, but also more waiting.

### Turning the angle into a turn
If you subtract 90 from the chosen angle, you find how far the robot needs to turn: `fark = aci - 90`. If the difference is positive, it turns left; if negative, right. The turning time is taken as `|fark| × 5 ms`. Example: if 150° was chosen, the difference is 60° and the turn takes about 300 ms.

### Scanning is not a cure for everything
If every direction is close, the "farthest" direction is a wall too. If even the farthest measurement is small, the robot is stuck; we will deal with this case in lesson 84.

### Summary
The servo gives the robot a way of looking by turning the sensor. The robot measures each direction, keeps the largest value and its angle, and turns the chosen angle into a turning time. Do not measure while the servo is moving; wait after each angle. The price of scanning is time.
