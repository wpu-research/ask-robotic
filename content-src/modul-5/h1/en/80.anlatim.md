### The safe state is the default
On a remote-controlled robot, the worst moment is when control is lost silently. A safe robot moves "while commands keep coming" and stops when they stop. This idea is called a **watchdog**. The watchdog counts time; if no valid command arrives within a certain time, it stops the robot. In the project the time is `CMD_TIMEOUT = 700 ms`.

### A two-state machine
| State | Motors | LED | Exit |
|---|---|---|---|
| DURUYOR (stopped) | stopped | off | if a valid motion command arrives: SURUYOR |
| SURUYOR (driving) | according to the last command | on | if `X` arrives or no command for 700 ms: DURUYOR |

Important rules: at start-up the robot is in the DURUYOR state (motion has to be requested with a command). Every **valid** command resets the time. An **invalid** command does not reset it; otherwise random noise could keep the robot driving forever.

### Checking the time
The check is done in the form `millis() - sonKomut >= CMD_TIMEOUT`. The subtraction method gives the right result even when the `millis()` counter overflows (lesson 27). The check is done in `loop()` without `delay`; otherwise reading the commands would be blocked.

### Calculate the price
After the commands stop, the robot travels a little further:

```
distance = speed × CMD_TIMEOUT
```

For 20 cm/s and 0.7 s that is 14 cm; for 39 cm/s it is about 27 cm. A short time is safer, but if the connection delay varies, the robot stops for no good reason. The sending side must repeat the command more often than the watchdog time; in the project, every 200 ms. If the time is shorter than the repeat interval, the robot keeps stopping and starting.

### Command language and turning
The speed is now in cm/s, and `hizdanPwm` (lesson 78) turns it into PWM. When turning on the spot, each wheel turns in the opposite direction at speed v: ω = 2·v / L. For 12 cm/s, ω = 2 rad/s, which is about 115° per second.

### Summary
The command-driven car brings together all of this week's parts and adds a safety layer on top: if no command arrives, the robot stops by itself. The watchdog is a simple state machine that keeps track of the time of valid commands. Choosing the time is a trade-off: a short time is safe but sensitive, a long time is tolerant but dangerous. Always check the stopping distance by measuring it.
