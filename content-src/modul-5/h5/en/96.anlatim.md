### Error, setpoint and output
When you ride your bike close to the edge of the road, you turn the handlebars according to the size of the error. This is the language of control too. The **setpoint** is where the robot wants to be: with the line exactly in the middle of the array. The **error** (e) is the difference between the setpoint and the measurement; if the error is 0, the robot is where it wants to be. The **control output** (u) is the robot's steering.

### Turning the array reading into a position
Each of the five sensors is given a weight:

```
sensor:   A0   A1   A2   A3   A4
weight:   +2   +1    0   -1   -2
```

The average of the weights of the sensors that see the line is the line's **position**. A positive position tells you the line is to the robot's left. Because the setpoint is 0, the position itself is the error. If only A0 and A1 see the line, the position is (2 + 1) / 2 = 1.5. If no sensor sees it, there is no position; in this case the safest choice is to say "far away" towards the side where the line was last seen.

### P control
**P (proportional) control** gives steering in direct proportion to the error:

```
u = Kp x e
left wheel  = TABAN - u
right wheel = TABAN + u
```

**Kp** is the number that turns the error into steering. If the line is on the left (`e > 0`), the left wheel slows down, the right wheel speeds up and the robot turns left. If the error doubles, the steering doubles too. This is the difference from bang-bang: there you made the same sharp turn for every error.

### How do you choose Kp?
In the simulation we tried four different Kp values on the same track:

| Kp | Result |
|---|---|
| 8 (too small) | not enough steering, the line was lost |
| 85 and 210 | lap finished, the error got smaller |
| 830 (too large) | lap finished but the steering kept wiggling and the lap took longer |

If Kp is too small, the robot cannot take the bend. As it grows, the error gets smaller, but after a point the gain drops off and the robot starts to jitter. Start small, double it each time and measure.

### Summary
P control steers as much as the error: `u = Kp x e`. A weighted average of the line array gives the position, and this position is used as the error. If Kp is too small, the robot loses the line; if it is too large, the robot jitters. That is why you start Kp small and increase it while measuring.
