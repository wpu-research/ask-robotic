### What you will learn in this lesson
- Giving the robot's state to someone else with a **data contract** (JSON lines)
- Tying the type and valid range of every field in the line to a rule
- Writing a missing measurement as `null`, not as a fake number
- Working out the mean absolute error and the largest absolute error

### There is no 3D view yet: we are preparing the interface
In this lesson we are not running a view that shows the robot in 3 dimensions; there is no such thing at the moment. The job is to set up and test the interface that such a view (or a graph, or a log file) will be fed from in the future: the robot writes its state over the serial line in a fixed format.

### The data contract
A single line every 100 ms, a JSON object:

| Field | Meaning | Valid value |
|---|---|---|
| `t` | `millis()`, ms | an integer of 0 or more |
| `x`, `y` | odometry position, metres | -10 to 10 |
| `th` | heading, radians | greater than -π, equal to or less than π |
| `d` | distance in front, cm | 2-400 or `null` |

The field names and their order are fixed: `t, x, y, th, d`. You agree on the format once; both the sender and the receiver trust it. That is why the values are bound by rules. `th` is wrapped into the range (-π, π] so that it does not become 7 after a few turns. If there is no measurement, writing a fake number such as 0 or 400 for `d` misleads the receiver; the right thing is `null`. In JSON the decimal separator is a point.

Speed is part of the contract too. A line of about 50 bytes stays on the line for 50 × 10 / 9600 ≈ 52 ms at 9600 baud (one byte is 10 bits: start, 8 data, stop). That is half of the 100 ms period. At 115200 baud it is less than 5 ms.

### Measuring error
How far a measurement is off is described with two numbers:
- **Mean absolute error:** the average of the unsigned value of each error. The absolute value is a must; +3 and -3 should not cancel each other out.
- **Largest absolute error:** the worst measurement. The average may be good while a single measurement is very bad.

Example: if the errors are 0.5; -2.5; 1.0; -1.0; 2.0, the signed average is 0, but the absolute average is 1.4 and the largest is 2.5. The signed average would give the wrong conclusion that "the robot is perfect".

### The direction of odometry
If the right wheel goes further than the left, `Δθ = (sağ − sol) / aks` (right − left, divided by the axle) is positive; the robot turns left. If you write the sign the wrong way round, `th` decreases while the robot turns left and the path you draw is mirrored.

### Summary
Writing the robot's state over the serial line as contract-bound JSON lines lets the receiver (3D view, graph, log) be prepared; the ranges are bound by rules, and a missing measurement is written as `null`. The error is averaged with absolute values, and its largest value is reported too. The baud rate sets how many ms a line takes up on the line.
