# 74HC595 shift register
slug: sr595
category: Output
summary: A chip that turns three Uno pins into eight outputs. It receives bits serially, drives eight pins at once and can be chained.

## Pins
- QA: Output 1 (bit 0).
- QB: Output 2 (bit 1).
- QC: Output 3 (bit 2).
- QD: Output 4 (bit 3).
- QE: Output 5 (bit 4).
- QF: Output 6 (bit 5).
- QG: Output 7 (bit 6).
- QH: Output 8 (bit 7).
- SER: Serial data input; the bits arrive on this wire.
- SRCLK: Shift clock; one bit shifts in on each rising edge.
- RCLK: Latch clock; on a rising edge the byte inside is copied to the outputs.
- OE: Output enable (active-LOW). If connected to GND the outputs are on; if connected to 5V they are off.
- SRCLR: Register clear (active-LOW). If connected to 5V it works normally; if on GND the register is cleared.
- QH_: Serial output (QH'). Connect it to the SER lead of the next chip to build a chain.
- VCC: Supply, 5V.
- GND: Ground.

## How it works
The **74HC595** is a shift register that turns bits arriving one after another into eight outputs. The Uno sends the bits on the SER wire, and one bit shifts in each time SRCLK gets a pulse. Once eight bits are in, RCLK (the latch) goes high and copies the byte to the outputs all at once. The outputs do not change before the latch.

`shiftOut(veri, saat, MSBFIRST, bayt)` (data, clock, MSBFIRST, byte) does this job. With MSBFIRST the most significant bit goes first; the last bit sent, bit 0, ends up on QA. The latch is driven by one pin: `digitalWrite(mandal, LOW)`, `shiftOut`, `digitalWrite(mandal, HIGH)` (mandal = latch). Three pins (SER, SRCLK, RCLK) are enough.

If there is a second chip, the first chip's QH_ lead connects to the second chip's SER lead; the clock and latch are shared by both. This way you get 16 outputs from three pins.

**Advanced:** Each output can only supply a limited current on its own (on the real chip up to about 35 mA per pin is allowed); every LED needs its own resistor.

## Wiring in the lab
| From | To |
|---|---|
| **VCC** and **SRCLR** | **5V** |
| **GND** and **OE** | **GND** |
| **SER** | Uno **D4** |
| **SRCLK** | Uno **D6** |
| **RCLK** | Uno **D5** |
| **QA** ... **QG** | Through resistors to the display's a ... g leads (or to LEDs) |

If you leave OE and SRCLR unconnected, the lab shows an "unconnected input" warning: if OE is left open the outputs are treated as off, and if SRCLR is left open the register is treated as constantly cleared. If VCC and GND are not connected, an "unpowered" warning appears; there is no output.

## Typical values
- Number of outputs | 8 | QA-QH
- Uno pins needed | 3 | SER, SRCLK, RCLK
- Output resistance | 50 Ω | Lab model
- Counts as powered | 4 V and above | Difference between VCC and GND
- Chain of two chips | 16 outputs | Still 3 Uno pins

## Common mistakes
- **Not using the latch.** The bits shift in but the outputs do not change; the display stays blank.
- **Wiring OE or SRCLR wrong.** If you connect OE to 5V or SRCLR to GND, the chip gives no output or clears the register.
- **Forgetting the power wires.** If VCC and GND are not connected, the chip does not work.
- **Mixing up the bit order.** If you write LSBFIRST instead of MSBFIRST, the pattern appears in the reverse direction.
- **Not giving each output a resistor.** The LED or bar draws too much current.
