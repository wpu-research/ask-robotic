# LCD 16x2 display
slug: lcd1602
category: Output
summary: A character display that shows 16 characters on each of two lines and is driven with 6 signal pins (in 4-bit mode).

## Pins
- VSS: Ground. Connects to GND.
- VDD: Power supply, 5V.
- V0: Contrast pin. Usually connected to the middle pin of a potentiometer.
- RS: Command / data select. Driven by the Uno.
- RW: Read / write select. Connects to GND (we only write).
- E: Enable pulse. Driven by the Uno.
- D0: Data bit 0 (left unconnected in 4-bit mode).
- D1: Data bit 1 (left unconnected in 4-bit mode).
- D2: Data bit 2 (left unconnected in 4-bit mode).
- D3: Data bit 3 (left unconnected in 4-bit mode).
- D4: Data bit 4. Connects to the Uno.
- D5: Data bit 5. Connects to the Uno.
- D6: Data bit 6. Connects to the Uno.
- D7: Data bit 7. Connects to the Uno.
- A: Backlight positive pin. Connects to 5V through a resistor.
- K: Backlight negative pin. Connects to GND.

## How it works
An **LCD 16x2** shows 16 characters on each of two lines; each character is drawn from 5x8 dots. Most displays carry an HD44780 controller. When working with the Uno in **4-bit mode**, 6 signal pins are enough: RS, E and D4-D7; D0-D3 are left unconnected.

In the program you create a `LiquidCrystal lcd(RS, E, D4, D5, D6, D7);` object, start the display with `lcd.begin(16, 2)`, and write with `lcd.setCursor(column, row)` and `lcd.print()`. Counting starts at 0. The LCD does not erase old characters; new text is written over them.

**V0** sets the contrast. If its voltage is too high, the characters are invisible. The backlight is independent of the text; even if the light is on, the screen looks blank when the contrast is not right.

**Advanced:** The display draws characters from dots, 5 columns x 8 rows; you can define 8 custom characters with `createChar`. Because it needs many pins, the same display can also be driven with two wires through an I2C adapter (the lcdI2c part).

## Wiring in the lab
| From | To |
|---|---|
| **VSS**, **RW** and **K** | **GND** |
| **VDD** | **5V** |
| **A** | **5V** through a 220 Ω resistor |
| **V0** | Potentiometer **SIG** pin (pot VCC = 5V, GND = GND) |
| **RS** | Uno **D12** |
| **E** | Uno **D11** |
| **D4**, **D5**, **D6**, **D7** | Uno **D5**, **D4**, **D3**, **D2** |

In the lab, for text to appear, VDD must be at least 4 V and VSS and RW must be connected to ground. If the V0 voltage goes above about 1.6 V, the screen looks blank; if V0 is not connected at all, the text is visible. The backlight counts as on when more than 1 mA flows between A and K.

## Typical values
- Size | 16 columns x 2 rows | 32 characters
- Number of signal pins | 6 | RS, E, D4, D5, D6, D7 (4-bit mode)
- Contrast limit (V0) | 1.6 V | Above this the screen looks blank (lab model)
- Backlight Vf | 3 V | Lab model
- Backlight turn-on threshold | 1 mA | A-K current
- Number of custom characters | 8 | Slots 0-7

## Common mistakes
- **Mixing up the pin order.** The order in `LiquidCrystal lcd(12, 11, 5, 4, 3, 2)` is RS, E, D4, D5, D6, D7; the code and the wires must match.
- **Not adjusting the contrast.** If the V0 voltage is high, the screen looks blank; turn the potentiometer down.
- **Not connecting VSS, VDD or RW.** The display does not turn on; connect RW to GND.
- **Not writing `lcd.begin(16, 2)`.** The display is not initialised.
- **Not clearing old text.** If short text is written over longer text, the old characters stay.
- **Using Turkish letters.** ı, ş, ğ are not in the display's character table.
