### What you will learn in this lesson
- What a **variable** is and why we think of it as a "labelled box"
- How to put a value in a box and make the value in the box bigger or smaller
- How to show the number inside the box on the screen
- How a counter program works

### What you should know first
- Lesson 6: button events (putting jobs inside the A, B and A+B blocks)
- Lessons 1-5: the **show number** block and the **on start** header block

### What does the card remember?
When an event is over, everything inside the block is forgotten. When you press A a second time, the card does not know about the first press by itself. You need to write it down somewhere. That place is a **variable**.

### Variable: a box with a name
A variable is a box with its name written on it. There is always just one value in the box. When you put a new value in the box, the old one is wiped. You choose the name: **sayi** (number), **puan** (score), **zar** (dice). The name should tell you what is inside.

### Three things you can do with a box
| Block | What it does | Example (when the box is 4) |
|---|---|---|
| set sayi to [7] | Wipes the old one, puts the new one in | The box becomes 7 |
| change sayi by [3] | Adds to the current number | The box becomes 7 |
| sayi | Reads what is inside | Gives 4 |

If you add a minus number, the number in the box gets smaller: if you add -1 to 4, it becomes 3.

### The name of the box, or what is inside?
In the **show number [sayi]** block, what is written on the screen is not the name of the box but the number inside it. If the box is 3, the screen shows 3. Also, changing the variable does not change the screen. If you want to see it on the screen, you need to use the show number block too.

### Starting value
Putting a value in the box on purpose at the start of the program is a good habit. If you put **set sayi to 0** in the **on start** block, the counter starts from zero every time you press ▶. Anyone reading the program can also see what it starts with.

### How does a counter work?
When A is pressed, three things happen in order: the card looks in the box, adds 1 and puts the new number in the box. Then it shows it on the screen. On the first press 0 + 1 = 1, on the second 1 + 1 = 2. Each press uses the number left from the press before. The variable builds the bridge between events.

### Summary
A variable is a box that has a name and holds one value. You manage it with the set, change and read blocks. To see it on the screen, you need the show number block. Resetting the box at the start of the program keeps counters working properly. A counter is a program that, at every event, reads the old value in the box and adds to it.
