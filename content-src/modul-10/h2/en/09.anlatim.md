- When the long press event runs
- How to give the same button both a short-press job and a long-press job

### What you should know first

### The logo: a touch star
The star-shaped logo on top of the card is touch-sensitive. On the virtual card, if you hold the mouse down on it, it counts as "touched"; if you let go, it counts as "released". The logo has two events:

| Event | When |
|---|---|
| touched | The moment your finger touches the logo |
| released | The moment your finger leaves the logo |

It is the same idea as with the buttons: you can give two separate jobs to two separate blocks. For example, a heart when touched and clear screen when released.

### Time: 1 second
The **long pressed** event runs **1 second (1000 ms)** after the moment you press the button, if the button is still pressed. If you press for 0.9 seconds and let go, the event never comes. Once it has run, it does not run again, even if you keep holding the button.

### How many events in one press?
If you write a **pressed**, a **long pressed** and a **released** block for one button, a very long press triggers all three. The order is like this:

```
t = 0 ms     pressed runs
t = 1000 ms  long pressed runs
t = 2500 ms  (finger lifted) released runs
```
In a short press (say 300 ms), only pressed and released run; the long event does not come.

### The secret button idea
A long press is good for jobs that should not run by accident. That is why the "reset" buttons on toys often need a long press. If you want something to be easy to do, give it to a short press; if you want to protect a serious job, give it to a long press.

### Things to watch out for
- Choose the right list in each block. If **touched** stays in both blocks, both of them run when you touch.
- One screen action writes over another: the block that runs later is what you see.

### Summary
The logo is a source of events like A and B, and it gives the touched and released events. The long pressed event comes once if the button stays pressed for 1 second. A short press produces pressed and released; a long press adds the long event to them. Each event gives a job to its own block; choosing the right list is important.
