### Waiting is a program too
Until now, programs started by themselves and flowed from start to finish. Real devices often do not work like this. Inside a lift, everything waits quietly until you press a button. When you press it, something happens, and then it waits again. Computer people call this "when something happens" situation an **event**. A button being pressed, a button being released and the logo being touched are all events.

### Event block: a header block
The **on button [A] [pressed]** block is a header block, like **on start**. But it does not run straight away. First it sleeps. When the event comes, the blocks inside it run from top to bottom, and when they are done, the block goes back to sleep. If the same event comes again, it runs again.

### Three buttons, three moments
There are two buttons on the card. Underneath the virtual card there is also an **A+B** button that presses both at once. For each button you can choose three moments:

| Moment | When it runs |
|---|---|
| pressed | The moment you press the button |
| released | The moment you lift your finger |
| long pressed | 1 second after you start holding it down |

So one short press produces two events: first pressed, then released.

### A+B is a special button
When A and B are pressed together, the card counts this as a **separate button**. Then only the A+B block runs, not the block of A or B. If you press A first and then B, A's block may already have run. To press both at the same time, use the **A+B** button underneath the virtual card.

### Every event lives in its own block
A program can have as many event blocks as you like. Three blocks written for A, for B and for A+B are independent of each other. Careful: if **A** stays selected in the lists of both blocks, both of them react to A, and nothing happens for B. The button list is the block's "address".

### Summary
An event is a rule: "when something happens, do this". An event block is a header block; it sleeps and runs when the event comes. Every button has the moments pressed, released and long pressed. A+B is a separate event and does not run the blocks of A and B. A program can have several event blocks.
