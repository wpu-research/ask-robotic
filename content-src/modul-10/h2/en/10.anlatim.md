### What you will learn in this lesson
- How to put a project into a rules table before coding it
- How a variable that keeps a total (an accumulator) works
- How to bring the button event, variable, random number and if blocks together in one program
- That a block that plays music makes the program wait for as long as the music lasts

### What you should know first

- Lesson 7: variables, the change block, starting values

### Rules table first
Split the big job into small parts. On the scoreboard, three buttons do three separate jobs:

| Event | What it does | Variable it uses |
|---|---|---|
| On start | Sets the total to 0 | toplam |
| A pressed | Rolls the dice, adds it to the total, shows the dice, plays a melody on a 6 | zar, toplam |
| B pressed | Shows the total | toplam |
| A+B pressed | Resets the total, shows 0 | toplam |

Once you have written the table, coding is just filling it in in order.

### Two variables, two jobs
**zar** (dice) holds the current roll and changes with every A. **toplam** (total), on the other hand, collects all the rolls and is only ever added to. An example: if the rolls are 4, 6, 3, the total goes 0 → 4 → 10 → 13. It never gets smaller until you reset it.

### Order matters
In the A block the order is: first roll the dice and put it in the box, then add it to the total, then show it, and finally ask whether it is a 6. Add the **zar** box to the total; do not put a new random block. That way the number you see on the screen is the same as the number that goes into the total.

### Waiting while the melody plays
The **play melody** block makes the rest of the block wait until the melody is over. The Fanfare melody is 5.5 beats long; at a speed of 120 beats per minute, one beat is 500 ms. So the melody takes 5.5 × 500 = 2750 ms. Because the digit also stays on the screen for a short time, an A press that rolls a 6 keeps the card busy for about 3 seconds. Meanwhile, new presses wait in the queue.

### Resetting
If you do not reset the total with A+B when you start a new game, the old game's score stays. The on start block also resets the total every time you press ▶. Both ways put 0 in the same box.

### Summary
First you write the rules table, then you build the blocks. zar holds the last roll, toplam holds all the rolls. The zar box is added to the total; a second random block is not added. The block waits until the melody is over. The reset block makes the total 0 again, so a new game starts.
