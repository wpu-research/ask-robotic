### Random number: the card's dice
The **random number from [1] to [6]** block gives 1, 2, 3, 4, 5 or 6 every time it runs. Both ends are included, so 1 and 6 can both come up. 0 or 7 never come up. Neither you nor the card knows in advance which number will come up. On a fair dice every face has the same chance: the chance of getting a 6 is one in six.

### Rolling the same dice twice
Every time the random block runs, it rolls a **new** dice. If you put two separate blocks, one to show the number on the screen first and one to check whether it is a 6, you have rolled two separate dice. While you see 3 on the screen, the card may have seen 6. The fix: roll the dice once and put the result in the box called **zar** (dice). Use the box both when showing and when comparing.

```
zar = randomInt(1, 6);
screen.showNumber(zar);
if (zar == 6) { ... }
```

### If ... then: asking a question
The **if** block asks a question. If the answer is true, the blocks inside it run; if it is false, the inside of the block is skipped and the program carries on below. Questions are asked with the **comparison** block: **=**, **≠**, **<**, **≤**, **>**, **≥**. The result of a comparison is "true" or "false".

| Question | When zar is 6 | When zar is 4 |
|---|---|---|
| zar = 6 | true | false |
| zar > 4 | true | false |
| zar ≥ 4 | true | true |
| zar ≠ 6 | false | true |

### Assignment and comparison are different
**set zar to 6** is a command: it puts 6 in the box. **zar = 6** is a question: is there a 6 in the box? The command changes the box; the question does not. If you mix them up, the dice always comes up 6.

### If and else
You can add an "else" branch to the if block. If the question is true, the top branch runs; if it is false, the bottom branch runs; they never both run. Showing a heart when a 6 comes up and a sad face when it does not is an example of this.

### Summary
The random number block makes a new whole number every time it runs, including both ends. If you are going to use a result in several places, store it in a variable. The if block runs or skips its inside depending on a comparison question. The set command changes the box; the = question looks at the box. The else branch runs exactly one of the two options.
