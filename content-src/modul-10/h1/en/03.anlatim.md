### What you will learn in this lesson
- How to draw on the screen in one step with the ready-made **icon** block
- How to draw your own pattern of 25 switches with the **show LEDs** block
- That a pattern can be read row by row as "1 on, 0 off"
- That a new drawing wipes the previous one, and that you need a pause between two drawings

### What you should know first
Lesson 1: the block editor and the fact that blocks run in order. Lesson 2: LED addresses (x, y), counting from 0 and the time of the **pause** block in milliseconds.

### Lighting them one by one is tiring
In lesson 2 you drew a shape one LED at a time with plot blocks. A face could need ten blocks. That is why there are two shortcuts: ready-made icons and your own pattern.

### Ready-made icons
The list in the **show icon** block contains ready-made drawings such as a heart, faces, arrows, a square and a note. When you choose one, the drawing appears on the screen straight away. The icon **stays** on the screen until you clear it or show something else; it does not disappear by itself just because a block has finished its job.

### Pattern: 25 switches
The 25 LEDs on the screen are really 25 tiny switches; each one is either on or off. A **pattern** is the state of these switches at that moment. The **show LEDs** block has 5 x 5 boxes, and each box is a switch. You can write a pattern on paper like this; 1 means on, 0 means off:

```
row 0:  0 0 1 0 0
row 1:  0 1 1 1 0
row 2:  1 0 1 0 1
row 3:  1 1 1 1 1
row 4:  1 0 1 0 1
```

This is a robot head. You read each row from left to right; the columns that are lit are where the 1s are in that row. For example, in row 2 the 1s are in columns 0, 2 and 4. The total number of lit LEDs is 1 + 3 + 3 + 5 + 3 = 15. You can check your drawing by counting like this.

### The next drawing wipes the previous one
The **show icon** and **show LEDs** blocks redraw the whole screen; the previous drawing is completely gone. They do not pile up on top of each other. That is why, if two drawings are placed one after the other with no pause in between, only the last one is seen: the first one stays for such a short time that nobody notices it.

If you line up two drawings with a **pause** between them, you get a simple **animation**. A cinema film is also lots of drawings, each slightly different from the one before, shown quickly. If you make the pause shorter, the animation speeds up; if you make it longer, it slows down.

### Careful: there is another block for text
**show LEDs** does not write letters; it only shows the pattern you drew. For text, use the **show text** block.

### Summary
show icon puts ready-made drawings on the screen, while show LEDs puts the 25-switch pattern you drew yourself. A pattern can be written row by row with 1s and 0s. A new drawing wipes the previous one, so you make an animation by putting pauses between them.
