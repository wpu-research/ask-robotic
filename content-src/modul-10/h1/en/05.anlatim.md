### What you will learn in this lesson
- The difference between the **on start** (once) and **forever** (without stopping) blocks
- How a rhythm is built with pause times
- That the **set screen brightness** block works between 0 and 255
- How to plan a big job by first splitting it into parts and putting them in a table

### What you should know first
Lesson 1: showing text and header blocks. Lesson 2: **pause** and milliseconds. Lesson 3: **show icon** (heart and small heart). Lesson 4: the order of blocks and repetition.

### Two separate header blocks
Until now you put everything in the **on start** block; that part runs once and ends. A beating heart, though, should not end. The **forever** block repeats what is inside it from the start until you press ■ Stop. The jobs are shared out like this:

| Part | When it runs | What you put in it in this project |
|---|---|---|
| on start | Once, at the start | Set the brightness, show the greeting text |
| forever | Again and again without ending | The heartbeat |

If you put the text inside forever by mistake, the heart waits for the text to finish again in every round; the beat never looks right.

### A rhythm is the total of the pauses
A real heart goes "lub-dub, rest". On the card you show this as big heart, small heart, big heart, small heart, and you put pauses of different lengths in between:

```
big heart      150 ms
small heart    100 ms
big heart      150 ms
small heart    400 ms  (long rest)
total          800 ms
```

One round takes 800 ms. Since a minute is 60 000 ms, that makes about 60 000 / 800 = 75 rounds a minute. If you shorten the pauses, the heart speeds up; if you make them longer, it slows down. You set the rhythm you want with these numbers.

### Brightness
The **set screen brightness** block sets the brightness of all the LEDs. The value is between **0 and 255**: 255 is the brightest, and 0 is when nothing is visible. Do not think the program is broken; if the brightness is 0, the screen is dark even when something is drawn. Turning the screen down is easier on your eyes, especially in a dark room.

### Plan first, then blocks
As a project gets bigger, writing a small table first, instead of dragging blocks straight away, makes your job easier:

| Step | Part | Job |
|---|---|---|
| 1 | on start | Set the brightness to 200 |
| 2 | on start | Show the text "Sev" |
| 3 | forever | Heartbeat: four drawings, four pauses |

Each row matches one or a few blocks. When you write the plan like this, you know which block goes where.

### Summary
on start runs once; forever runs all the time. The rhythm of the beating heart is the total of the pause times; in this project a round is 800 ms. Brightness is between 0 and 255, and 0 makes the screen dark. Starting the job by putting the plan in a table cuts down mistakes.
