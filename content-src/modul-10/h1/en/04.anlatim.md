### What you will learn in this lesson
- That the same blocks give a different result in a different order
- How to use the **repeat** block to have a job done more than once
- The difference between a block being **inside** repeat or **under** it
- How to work out the total time of a program that repeats

### What you should know first
Lesson 1: blocks run from top to bottom. Lesson 2: the time of the **pause** block in milliseconds and **clear screen**. Lesson 3: the **show icon** block.

### Order changes the result
In a recipe, if you stir before cracking the egg, the result goes wrong. It is the same on the card. These two stacks are made of the same four blocks:

```
Stack 1: show square -> pause 300 -> clear -> pause 300
Stack 2: clear -> pause 300 -> show square -> pause 300
```

When stack 1 finishes, the screen is empty. When stack 2 finishes, the square is left on the screen. The **final state** of a program is the state left by the last block that ran.

### Repeating instead of copying
To make the square blink three times, you could line up the four blocks three times; that makes 12 blocks. But what if it had to blink 100 times? That is what the **repeat** block is for. The blocks you put inside it run from start to finish as many times as the number you type. This kind of structure is called a **loop**.

This is the JavaScript version of the repeat block:

```
for (let _i = 0; _i < 3; _i++) {
  ...
}
```

Here `_i` is a counter. It starts at 0, goes up by 1 in each round and stops when it reaches 3. So it goes round exactly three times: 0, 1, 2.

### Inside or outside?
If a block is **inside** the repeat block, it runs in every round. If it is **under** it, it runs once after the loop has completely finished. The difference looks small, but the result is big: if you put the "yes" icon inside, the card tries to show it in every round; if you put it outside, it appears only once, at the very end.

### Working out the total time
The time of the loop is the time of one round times the number of rounds. If you wait 300 ms with the square on and 300 ms with it off in one round, the round takes 600 ms. The total for three rounds:

```
3 x (300 + 300) = 1800 ms = 1.8 seconds
```

Being able to do this sum helps you when you plan an animation. Remember: for the blink to be visible, you need both **clear** and two **pause** blocks. Without clearing, the square never goes off; without pausing, the change happens too fast for your eyes to see.

### Summary
The same blocks give a different result in a different order. The repeat block runs the blocks inside it as many times as the number and saves you the trouble of copying. What is inside runs in every round; what is outside runs once after the loop. The total time is the time of one round times the number of rounds.
