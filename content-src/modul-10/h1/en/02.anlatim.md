### What you will learn in this lesson
- That every LED has an (x, y) address, where x gives the column and y gives the row
- That counting starts at 0, so the largest address is 4
- How to switch a single LED on and off and how to clear the screen
- That LED blocks do not wait, and that the **pause** block decides how long something is visible

### What you should know first
Lesson 1: the Micro Card's 5 x 5 LED screen, the on start block and the fact that blocks run in order.

### An address on a grid
On a chessboard, when someone says "e4", the square's place is clear. The card's screen is a grid too, and every light has an address made of two numbers, written as **(x, y)**:

- **x** is the **column** number from left to right.
- **y** is the **row** number from top to bottom.

x comes first, then y. The diagram below shows the four corners and the middle of the screen:

```
        x=0  x=1  x=2  x=3  x=4
y=0     (0,0)                 (4,0)
y=1
y=2               (2,2)
y=3
y=4     (0,4)                 (4,4)
```

### Why do we start at 0?
Computers usually start counting at **0**. The first item in a row is item "zero". If there are five columns, their numbers are 0, 1, 2, 3, 4; so the largest address is **4**, not 5. This is where beginners get stuck most often. Remind yourself: "There are five, but the last number is four."

### Switching on, switching off, clearing
The **plot** block switches on the light at the given address, and the **unplot** block switches off the same address. **clear screen** switches off all 25 lights at once. It is much quicker than switching them off one by one.

An address outside the screen, for example (7, 2), does not produce an error message. The card quietly ignores that block. This calm behaviour is a trap: even if there is a wrong number in your code, you will not see a red warning; the light just does not come on. If a light does not come on, check the addresses first.

### LED blocks do not wait
If you put five **plot** blocks one after the other, all five light up almost at the same time. The **pause** block decides how long a drawing stays visible; its time is in **milliseconds** (ms). 1000 ms is one second. If you put **clear screen** straight after a drawing, the drawing is visible for too short a time for your eyes to see.

A little sum: the outer frame is the lights that are left when you take the inner 3 x 3 part away from the 5 x 5 screen. That makes 25 - 9 = 16 LEDs.

### Summary
Every LED has an (x, y) address: x is the column and y is the row, and both go from 0 to 4. The plot, unplot and clear screen blocks control the lights. Addresses outside the screen are quietly ignored. LED blocks do not wait; the pause block decides how long something is visible.
