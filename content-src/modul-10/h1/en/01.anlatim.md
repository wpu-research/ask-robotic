### What you will learn in this lesson
- The parts of the Micro Card (LED screen, buttons, logo, connection points) and what they do
- How a program is built in the block editor: a header block, blocks attached underneath, ▶ Run
- That blocks run from top to bottom, in order
- That text is shown by scrolling, while a single letter or a one-digit number stays in the middle

### What you should know first
Nothing. This is the first lesson of the module. It is enough that you can grab an object with the mouse and drag it.

### A small but complete computer
The Micro Card is a computer that fits in the palm of your hand. Its screen is made of 25 tiny lights (**LEDs**); these lights form a grid of 5 columns and 5 rows. There are **A** and **B** buttons on the two sides of the card and a **logo** surface in the middle. You will use the P0, P1 and P2 connection points at the bottom in later weeks. The card in this module is **virtual**: it runs inside the computer and needs no batteries or wires.

### What is a program, what is a block?
A computer only does what it is told. The written list of these instructions is called a **program**. In this module you build the program not by typing, but by snapping colourful **blocks** together. Each block does one job: "show text", "pause", "clear screen" and so on.

The **header block** decides where the blocks will run. The **on start** block is the part that runs once when you press the ▶ button. If a block is not attached to it, the card does not see it; it looks faded and does not run. You can think of it as a room without a door: you cannot get in.

### Order is everything
The card runs the blocks **from top to bottom**, one by one. It does not move on to the next block until the current one has finished. The two stacks below are made of the same blocks, but their results are different:

```
Stack A: text "Hi"  ->  number 7
Stack B: number 7  ->  text "Hi"
```

In A, Hi scrolls first, then 7 appears. In B, 7 appears first, then Hi scrolls. That is why "in which order" matters as much as "what to do".

### Text scrolls, a single character stays
Because the screen is only 5 columns wide, long text **scrolls** from right to left. While it scrolls, the card waits; the next block does not start until the text is done. A 7-letter word like "Merhaba" (Turkish for "hello") scrolls past in about 4 seconds. A single letter or a one-digit number fits on the screen and does not scroll; it stays in the middle for a little over half a second. A two-digit number (for example 25) is two characters, so it scrolls like text.

### The hidden side of the code
The editor has **JavaScript** and **Python** tabs. They show the written code that matches your blocks. You cannot change the text there; you can only read it. The blocks and the written code are the same program; they just look different. Reading written code gets you ready to move on to programming by typing later.

### Summary
The Micro Card is a virtual computer with 25 LEDs, two buttons and a logo. You build the program from blocks, and every stack of blocks must be attached to a header block. Blocks run from top to bottom, in order. Long text scrolls; a single character stays in the middle.
