### Sound is a number too
The card turns how loud the sound around it is into a number called the **sound level**. 0 means silence, 255 means a very loud sound. On the virtual card you give it with the Sound slider. At the start the value is about 20; you can think of this as "room noise".

### Choosing a threshold
A clap is a short, loud sound. To catch a clap, you compare the sound level with a **threshold** number. The threshold must be bigger than the room noise but smaller than a clap.

```
room noise          ~  20
clap                ~ 200
a good threshold    :  between 100 and 150
too low a threshold :  10  (even room noise is 20 > 10)
too high a threshold:  250 (a clap can never go past it)
```

If the threshold is too low, the counter goes up for nothing. If it is too high, it does not count any claps.

### Counter: a variable and adding to it
A **variable**, which is a box for a value, keeps its value from round to round. For the clap counter you use a variable called `alkis` (clap). You set it to 0 at the start. At every clap you say **change alkis by 1**. If you had only written "show number 1", you would always see 1 on the screen; for the counter to remember, a variable is essential.

```
on start:  alkis = 0
forever:
  if sound level > 150 then
    change alkis by 1
    show number alkis
  else
    bar graph sound level up to 255
```

### Showing takes time
Showing a one-digit number takes about 0.6 seconds (600 ms), and there is also a short 20 ms pause at the end of the round. So one round takes about 620 ms. If the sound stays loud, the counter goes up by one every round:

```
If the sound stays at 200, within 2000 ms:
rounds start at 0, 620, 1240, 1860 ms  ->  4 increases
```

With a short clap, the sound drops straight away; thanks to this time, the same clap is not counted twice.

### Summary
The sound level is a number from 0 to 255, and room noise is about 20. The threshold should be chosen bigger than room noise and smaller than a clap. To keep a count, you need a variable: it is set to 0 at the start and 1 is added at every clap. Showing the number takes about 600 ms; if the sound stays loud, the counter goes up again and again at that interval.
