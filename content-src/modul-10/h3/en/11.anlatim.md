### The card senses gravity
When you tilt the phone in your hand, the screen rotates. The phone knows which way it is being pulled. The **accelerometer** does this. The accelerometer measures the card's movement and which way gravity "pulls" the card. It takes measurements even when the card is lying on the table, because gravity is always there.

### Three axes
The measurement is given as three separate numbers. Each number describes one direction.

```
x : left (-)  <->  right (+)
y : back (-) <-> forward (+)
z : face down (-) <-> face up (+)
```

The unit is **milli-g**. About 1024 milli-g means the full strength of gravity. When the card lies face up, gravity is in the z direction. That is why the reading comes out as (x, y, z) = (0, 0, 1024). If the card is tilted all the way to the right, gravity moves to the x direction: (1024, 0, 0).

### How does a tilt become a "position"?
The card looks at the largest axis value. If this value is at least 700 and bigger than the other axes, the card counts as tilted in that direction. For example, the reading (650, 0, 900) is still "face up": z is the largest and x has not reached 700. Shaking is separate: the card wobbles for a short time and the readings jump.

### An event only runs on a change
A block like **when card is [tilted left]** runs **the moment the card's state changes**. If the card is already tilted left, saying "tilt left" again changes nothing, so the block does not run again. For it to run, you first need to go back to another position, for example face up. Shaking is different: every shake is a new event.

### Deciding with a coin flip
The **coin flip** block gives **true** or **false** at random every time it runs. If you attach it to the condition of an if block, the program picks one of two paths at random:

```
when card is shaken:
  if coin flip then
    show icon yes
  else
    show icon no
```

If you leave out the "else" branch, half the time nothing happens: the old picture stays on the screen.

### Summary
The accelerometer measures on three axes in milli-g and knows the card's tilt thanks to gravity. If an axis is the largest and has reached 700, the card counts as tilted in that direction. Motion blocks only run when the state changes. Every shake is a new event. When you combine the coin flip block with the if block, you can make a magic ball that gives a random answer.
