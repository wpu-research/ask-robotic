### What is a sensor?
A **sensor** is a feeler that turns something around it into a number. A thermometer measures temperature; a light sensor measures brightness. On a real card, the sensors are physical parts. On the virtual card, **you** give the value with a slider; the program still sees it as a sensor reading.

```
temperature : -5 ... 50  (degrees)
light       :  0 ... 255 (0 dark, 255 very bright)
```

The starting values are 21 for temperature and 128 for light.

### A reading is a moment
The **temperature (°C)** and **light level** blocks read the value **at the moment** they run. If you change the temperature while the number is scrolling on the screen, the number on the screen does not change, because the reading has already been taken. To see the new value, the block needs to run again.

### Threshold: the decision boundary
A **threshold** is the boundary value where a decision changes. In the sentence "If the temperature is greater than 30, show a sad face", the threshold is 30. A comparison needs care right at the boundary:

```
when temperature = 30   30 > 30   false   (no sad face)
when temperature = 31   31 > 30   true    (sad face)
```

You decide which side the boundary value itself goes on by choosing ">" or "≥".

### Bar graph
The **bar graph [value] up to [largest]** block spreads a number over 25 LEDs. The LEDs fill up from the bottom. The sum is:

```
number of LEDs lit = nearest whole number( value / largest × 25 )
```

Example: if the value is 20 and the largest is 50, then 20 ÷ 50 = 0.4 and 0.4 × 25 = 10 LEDs light up. Because the light sensor goes up to 255, you type 255 as the largest value when you show the light. If you leave it at 5, the whole screen lights up as soon as the light goes past 5.

| value | largest | LEDs lit |
|---|---|---|
| 0 | 255 | 0 |
| 51 | 255 | 5 (bottom row) |
| 255 | 255 | 25 (all) |

### Summary
A sensor turns its surroundings into a number; on the virtual card, you give the value with a slider. A sensor block takes a reading at the moment it runs; a value that changes afterwards does not change the old reading. A threshold is the boundary where a decision changes, and depending on the comparison sign, the boundary value itself goes on one side or the other. A bar graph multiplies the value ÷ largest ratio by 25 LEDs and rounds it to the nearest whole number.
