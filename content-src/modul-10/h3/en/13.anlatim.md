### Degrees and direction
The compass tells you, in **degrees**, which way the top edge of the card is facing. The degrees start from north and go up clockwise.

```
   0 = North
  90 = East
 180 = South
 270 = West
```

One full turn is 360 degrees, but 360 is north again, so it is the same as 0. After 359 the number goes back to 0. That is why, if the card turns another 20 degrees to the right from 350 degrees, the compass shows not 370 but 370 − 360 = 10.

### The arrow's angle: why 360 minus compass?
As you turn the card, north slides to another place relative to the card. When the card turns to the east (90), north falls to the card's left. Since the arrow is meant to point north, it must turn the **opposite** way by as much as the card has turned:

```
arrow angle = 360 - compass
```

| compass | 360 - compass | arrow |
|---|---|---|
| 0 | 360 (= 0) | up |
| 90 | 270 | left |
| 180 | 180 | down |
| 270 | 90 | right |

If you make the arrow's angle the compass value directly (or add 360 to it), the arrow turns **together** with the card and does not point north.

### The arrow points in eight directions
The card's screen is 5×5, so the arrow block only draws eight directions: up, up-right, right, down-right, down, down-left, left, up-left. It rounds the angle you give it to the nearest direction. 100 degrees is closest to 90 (right), so a right arrow comes up.

### Manage the screen from one place
The forever block redraws the arrow in every round. If you also write to the same screen from a button block, the two blocks wipe each other's drawings. That is why we ask about the button not as an **event**, but as the question **"A pressed?"**. That way only the forever block writes to the screen.

### Summary
The compass gives a number of degrees between 0 and 359: 0 is north, 90 east, 180 south, 270 west. 360 is 0 again. For the arrow that points north, the angle is 360 minus the compass, because the arrow must turn the opposite way to the card. The arrow points in eight directions and rounds the angle to the nearest direction. To avoid screen clashes, keep the drawing in a single loop.
