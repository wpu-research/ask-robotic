### Mode: which job now?
The station will show three sensors in turn. A variable called **mod** (mode) holds which sensor is selected:

```
mod 0 = temperature
mod 1 = light
mod 2 = sound
```

Every time you press the A button, the mode moves on by one. But after 2 it should not become 3; it should go back to 0.

### The remainder operation
The **remainder** is the number left over from a division. 7 ÷ 3 = 2, remainder 1. **The remainder of (mod + 1) ÷ 3** gives exactly this cycle:

| mod | mod + 1 | remainder of ÷ 3 |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 2 | 2 |
| 2 | 3 | 0 |

That way, however many times you press, the mode always stays in the range 0, 1, 2. After n presses, the mode is the remainder of n ÷ 3; after 7 presses the mode is 1.

### Get it ready first, then draw
The forever block does two jobs. First, it gets two variables ready according to the selected mode:

```
okuma : the value of the selected sensor
enCok : the largest value that sensor can have
         temperature 40, light 255, sound 255
```

Second, it draws on the screen: if B is pressed, the number; if not, **bar graph okuma up to enCok**. This is the only place that writes to the screen, so the picture does not get mixed up.

### The largest value sets the proportion
The same temperature gives a different bar with a different largest value:

| okuma | enCok | LEDs lit |
|---|---|---|
| 30 | 40 | 19 |
| 30 | 50 | 15 |
| 21 | 255 | 2 |

The third row is a common mistake: if you give temperature the scale of light (255), the bar hardly fills up at all.

### A chain of choices
For three modes you use two ifs, one inside the other: first you ask whether the mode is 0, and if not, whether it is 1. If it is neither, the mode is 2. Because of this, an unexpected value such as mode 3 always ends up in sound mode, since nothing catches it.

### Summary
The mode variable holds which sensor is being watched. The remainder operation (mod + 1) ÷ 3 keeps the mode in the 0, 1, 2 cycle. The program first gets the okuma and enCok variables ready, then draws on the screen from one place. The largest value should be chosen to match each sensor's real range; otherwise the bar is out of proportion.
