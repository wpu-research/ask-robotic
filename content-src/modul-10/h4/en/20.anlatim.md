### What you will learn in this lesson
- How to connect several inputs (buttons, pins) to a single **pattern**
- How to add the notes played to a **recording list**
- How to play the recording from the start **when the logo is touched**
- How to break a project into **plan, build, test** steps

### What you should know first
Lessons 16-19: playing notes, tempo, lists and the **for each item** loop, event hat blocks. You should also know how to light an LED on the screen (**plot x y**) and the **clear screen** block.

### Break the project down
The virtual piano looks big, but really it is the same small job repeated five times. First put the job into a table:

```
Key   Note   Column (x)
A     C      0
B     D      1
A+B   E      2
P0    G      3
P1    A      4
```

The table is the backbone of the code. Each key differs in only two things: the note it plays and the column it lights.

### The key pattern
The body of every key has four steps:

```
1. Plot an LED (x, 2)
2. Play the note for [1/8] beat
3. Add the note's frequency to the recording list
4. Clear the screen
```

First build only the A key and run it. If it works, copy its blocks, move them to the other hat blocks and change only the note and the column. This is the **get the small one working first, then multiply it** method; it makes finding mistakes much easier.

### The recording list
In the **on start** hat block, you give the **kayit** (recording) variable an **empty list**. On every key, the **add [note] to list kayit** block puts the note's frequency at the end of the list. If you press the A, B, A, P0 keys in this order, the list becomes:

```
kayit = [262, 294, 262, 392]     length 4
```

The add block runs after the note has been played, because the note block waits for its duration first. If you press the same key quickly, the card queues the presses (up to three); different keys, however, can run at the same time.

### Playback
You put a **for each item in list kayit** loop in the **when logo is touched** hat block. Inside the loop there is the **play tone [item] Hz for [1/8] beat** block. At tempo 120 each note is 250 ms; a four-note recording lasts 1000 ms. If the tempo is 80, one note is 375 ms and four notes are 1500 ms. The recording is never deleted; to delete it, you give the kayit variable an empty list again.

### Summary
Reducing a big project to a small table and a single pattern makes the job easier. Every key follows the light, play, record, clear steps. The recording is a list that collects the frequencies of the notes in order; playback plays this list from start to end with the for each item loop. The duration is found by multiplying the number of notes by the tempo unit.
