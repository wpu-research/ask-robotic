### What you will learn in this lesson
- The ideas of **tempo** and **beat**
- How to work out a note's duration with the formula `60000 / tempo`
- Why the **rest** block is part of the music
- What happens when the tempo changes, and that duration values depend on the tempo

### What you should know first
Lesson 16: you should know that the note block plays the note and waits until it has finished, and the ideas of frequency and Hz. You should also be able to use the button hat block.

### Tempo: the speed of the music
If you play the same song slowly and then fast, it sounds like a different song. In music this speed is called the **tempo**. On the card, the tempo says **how many beats are played in one minute**. It starts at 120: 120 beats per minute, so 2 beats per second.

### How many milliseconds is a beat?
One minute is 60 000 milliseconds. Whatever the tempo is, that many beats fit into one minute. So the duration of one unit is found like this:

```
duration of a 1/4 beat (ms) = 60000 / tempo
```

The values in the card's note list choose how many times this unit the note lasts:

```
Value        1/16   1/8   1/4   1/2   1    2
Units        0.25   0.5    1     2    4    8
```

At tempo 120, one unit is 500 ms. So a 1/8 beat is 250 ms and a 1/2 beat is 1000 ms. If the tempo is 60, the unit is 1000 ms; if the tempo is 240, it is 250 ms. **As the tempo gets bigger, the notes get shorter**, and the music speeds up.

### A rest is like a note
The **rest for [1/4] beat** block makes no sound, but it waits for the same time. Rhythm is made of gaps as much as of notes. If you play the same note several times in a row without a rest in between, the notes run into each other.

### The tempo block lasts
The **set tempo to [N]** block runs once, but every note and every rest after it is worked out with the new tempo. The value stays until a new tempo block comes. The card keeps the tempo between 20 and 400; if you write a number outside this range, it pulls it to the nearest limit. For example, if you write 500, the tempo becomes 400.

### Blocks that want milliseconds, not beats
The **pause [500] ms** block gives the real time in milliseconds and does not listen to the tempo at all. The note and rest blocks, however, change with the tempo. If you do not know this difference, you will be puzzled: "I raised the tempo, but the pause did not get shorter".

### Summary
The tempo is the number of beats per minute, and one unit lasts 60000 / tempo milliseconds. When the tempo goes up, the notes get shorter. The rest block waits for the same time without making a sound. The tempo block affects everything after it; the pause block does not depend on the tempo and wants milliseconds directly.
