### What you will learn in this lesson
- How to put several values into a **list** in order
- That list numbers start at **0**
- How to work through the items of a list in turn with the **for each item** loop
- How to work out the duration of ready-made melodies from the tempo

### What you should know first
Lessons 16 and 17: playing notes, frequency and tempo. You should also know how to make a **variable** and give it a value, and the **on start** hat block.

### Ready-made melodies
The card has nine ready-made melodies, and the **play melody** block plays a whole song with one block. Its duration depends on the total units of the melody's notes and on the tempo. For example, the Fanfare melody is 5.5 units long. At tempo 120 one unit is 500 ms, so the duration is 5.5 × 500 = 2750 ms. At tempo 60 the same melody lasts 5.5 × 1000 = 5500 ms.

### What is a list?
Putting in a block for every note takes a long time. A **list** holds many values in order in one box. Every value has a **number** (index), and the numbering starts at **0**:

```
ezgi = [262, 330, 392, 523]
index:   0    1    2    3
```

Here the length of the `ezgi` (melody) list is 4, but the number of the last item is 3. Item number 2 is 392, because we start counting from zero. Keep this difference of one between the "length" and the "last number" in mind.

### Where do you build the list?
You build the list inside the **on start** hat block. That block runs once when the program opens. So when a button is pressed, the list is already ready. If you forget to build the list, the variable is still a number, and the list block stops with the error "This block needs a list."

### For each item
The **for each item [item] in list [list]** block takes each value in the list in turn, puts it into the loop variable and runs the blocks inside it for that value. In a list with four items, the blocks inside run exactly four times:

```
for each item in list ezgi:
   play tone [item] Hz for [1/8] beat
```

Because this block plays the sound on every round, the four notes take 4 × 250 = 1000 ms in total (tempo 120, 1/8 beat). In code, the same thing appears as `for (oge of ezgi)`. The code tab writes Turkish letters in plain ASCII (`oge` is the Turkish word for "item").

### Summary
Ready-made melodies play with a single block, and their duration depends on the tempo. A list is a box that holds several values in order; the numbers start at 0, so the last number is one less than the length. You build the list in on start. The for each item block runs once with each value in the list, and the total time is the number of rounds multiplied by the time of each round.
