### Two parts, one message
A remote-controlled vehicle has two parts: the **remote** says what to do, and the **vehicle** does it. Only radio messages flow between them. Both Micro Cards run the same program, but one plays the role of the remote and the other the role of the vehicle. The "send" half of the program is useful on the remote, and the "receive" half on the vehicle.

### The table first
Writing the commands in a table before writing the code lowers the chance of making mistakes:

| Command | Remote movement | Vehicle screen | Servo |
|---|---|---|---|
| 1 | tilt left | left arrow | 45° |
| 2 | tilt right | right arrow | 135° |
| 3 | tilt forward | up arrow | 90° |
| 4 | tilt back | down arrow | 90° |
| 0 | button A | "no" icon | 90° |

90° is the middle of the servo. 45° turns 45 degrees to one side, and 135° turns 45 degrees to the other side; the difference between the two ends is 90 degrees. The servo angle is between 0 and 180; anything outside this range is clipped.

### Tilting is an event
The **when card is [tilted left]** hat block runs once when the card is tilted. The event only happens when the position **changes**. If the card is already tilted left and you try to tilt it left again, no new event happens. If you leave the hat block empty, that direction never sends a message.

### The vehicle side
The vehicle puts the number that arrives into the **komut** ("command") variable and asks in order: is it 1, 2, 3, 4, and if none of these, 0, that is "stop". In every branch it both shows an arrow and turns the servo. Because the last **else** branch is "everything else", it catches 0; if a number it does not know arrives (for example 9), it also behaves like "stop". This is a useful safety feature: on an unknown command, the vehicle stops.

### A link to real life
Here, if a message is lost or arrives wrong, the vehicle quietly stays in its old state. In real vehicles, safety measures are added, such as the vehicle stopping when the signal from the remote is cut off. Adding a "stops whatever happens" rule to your own project is a good habit too.

### Summary
The remote and the vehicle agree through the command table. The remote turns the card's tilt into a number and sends it by radio; the vehicle puts the number into a variable, shows an arrow with the **if** chain and turns the servo. The tilt event happens when the position changes. The table must be the same on both sides, and the last branch should stop the vehicle on an unknown command.
