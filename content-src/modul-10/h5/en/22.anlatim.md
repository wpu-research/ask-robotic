### Why is one type not enough?
A number is often enough: "command number 1". But if you want to say "temperature 28", you also have to say what the number measures. That is why the radio carries three types of message:

| Type | Sender | Receiver |
|---|---|---|
| number | radio send number | received [number] |
| text | radio send text | received [text] |
| name = value | radio send [name] = [value] | received [name] and received [value] |

### The name = value pair
The pair is made of a label and a number: the name "sicak" ("hot"), the value 28. The receiving side reads the name to work out what the message is about. If you want to send three readings at the same time, you use three different names (sicak, isik, ses for hot, light and sound), and the receiving side looks at the name and puts the value in the right place.

### Limits
A text can be at most **32 characters**, and a name at most **12 characters**. Anything longer is quietly **cut off** while it is being sent. For example, of a 40-letter text, only the first 32 letters arrive on the receiving card. Be careful when comparing names too: if a name is longer than 12 characters, the cut-off version is sent and does not match the full name on the receiving side. You must write the name exactly the same, letter for letter; "sicak" and `sıcak` are different names.

### Working out the message type
The receiving side does not ask directly what type the message is; it finds out with a name check. In text and number messages, **received [name]** is empty. So the question "is received name = sicak?" only comes out true for a name = value message; for the others, the **else** branch runs. This small pattern is the simplest way to tell several different messages apart in one hat block.

The value that arrives is a number; you can do calculations with it and compare it with a threshold. Text, on the other hand, is shown scrolling across the screen.

### Signal strength
The **signal strength** block gives how strongly the message arrived. Because there is no distance in the virtual radio, its value is always 200. On real radios it drops as the cards move apart.

### Summary
The radio carries number, text and name = value messages. A text is at most 32 characters and a name at most 12; anything longer is cut off. The sending and receiving sides must write the name the same. The receiving side tells the message type apart with **received [name]** and uses the number with **received [value]**. In the virtual radio, the signal strength is always 200.
